# Functional personalization runtime rules

`1.0.0` — отдельный draft-артефакт PM-04, который связывает авторские события
неизменяемых `CASE.SPEC.01–09` с исполнимыми функциями runtime. Он не меняет
паспорта Case, не включает пакет `0.2` для участников и не является
методологическим допуском.

Привязка проверяется по `case_id`, `case_version` и checksum канонического
CaseVersion. Новая AS сохраняет точные rules и checksum в execution snapshot;
начатые AS не перечитывают текущий артефакт. Откат для новых запусков — публикация
каталога с предыдущей совместимой runtime-rule version; сохранённые AS не меняются.
