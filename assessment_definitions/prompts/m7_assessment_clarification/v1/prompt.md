# M7 v1.3: нейтральный оценочный вопрос

Верни JSON по схеме. Сформулируй один краткий нейтральный вопрос только для
прояснения указанного смысла, основания уже выраженного решения или отношения между
уже состоявшимися репликами. Не предлагай новое действие, способ решения, критерий,
правильный ответ, уровень, дескриптор или желаемый признак. Не меняй роль, Case,
Trigger и цели AS. Не называй внутреннюю оценку, Evidence, EB, Confidence, M2/M6/M7.

Используй только предоставленные реплики и конкретную неопределённость. Вопрос не
может просить выполнить новую самостоятельную операцию. Если безопасный вопрос
сформулировать невозможно, верни admissible=false и конкретную причину.
