# ADM-UI-02 · Данные организации и предпросмотр

## Основание и область

Владелец поручил «приступи к выполнению» после ознакомления с архивом
`P4K_ADM_UI_02_Organization_Data_2026-11-20.zip`. Требования к форме и приёмке
взяты из `TASK.md` и трёх сцен локального HTML редакции 3 от 19 ноября.
Проверены SHA-256 всех 13 файлов в манифесте эталона. Рабочая база
`01787898da99e228ebd2a84a45f1f36cf56cd556` (2.1.55, [UI-01 #272](https://github.com/VadikB/4K_MBTI/pull/272)).
Ветка `codex/adm-ui-02-organization-data`.

Область включает экран «Управление → Данные организации», живой предпросмотр,
подтверждение и чтение исхода через действующий API. Обработка CSV, схема БД,
генерация ситуаций и операции других разделов ведутся по своим контрактам.

## Полномочия и откат

Текущий этап заканчивается передачей draft PR. `branch_push=true`,
`pr=true`, `version_bump=false`, `merge=false`, `deploy=false`,
`artifact_publish=false`. Требования к PR взяты из ТЗ, действие следует из

редакции и привязки сохранённых оценок остаются в истории.

## Приёмка и воспроизведение

Войдите как администратор синтетической организации с подключённой программой.
Откройте «Управление → Данные организации».

| Сцена | Действие и ожидаемый результат |
| --- | --- |
| Первое заполнение | Откройте организацию без редакций анкеты. Имя взято из записи организации. Видны три раскрытые карточки, незаполненные выборы C17 и отдельный предпросмотр с подсказками вместо отсутствующих сведений. |
| Частичное заполнение | Заполните первую карточку и нажмите «Подтвердить сведения». После ответа с недостающими полями откройте экран снова. Внесённые значения видны, а правки цели и использования результатов сразу отображаются справа. |
| Подтверждённые данные | Заполните оставшиеся поля и подтвердите. После подтверждения сервером на месте кнопки появляется «Сведения подтверждены». Правка возвращает кнопку и пояснение о действующей редакции. При правке имени сверьте оба названия и подтвердите переименование. Повторное открытие показывает сохранённое имя той же организации. |

На ширине 1440 px предпросмотр занимает 280 px справа от карточек. На 390 и
320 px он следует за формой. Вкладки, раскрытие готовности и подтверждение
доступны с клавиатуры.

При отказе или неизвестном исходе подтверждения «Проверить результат» читает
точный ID редакции. При конфликте выполняется сверка с сохранёнными данными,
после которой можно подтвердить актуальный черновик. Потеря ответа на POST
предпросмотра допускает повтор с прежним ключом при совпадающих ответах.
В проверке имени используется `expected_organization_name` из той же
серверной проверки, которая записала черновик. Это учитывает переименование,
сделанное другим администратором до отправки формы.
