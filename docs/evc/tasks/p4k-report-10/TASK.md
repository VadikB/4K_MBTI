Правило M8 v1.2: отсутствие результата не ноль; частичный Score и отсутствие общего Score различаются. REPORT-05 задаёт радар 0–3 без соединения через пропуски. REPORT-07 разрешает разность только при подтверждённой сопоставимости. REPORT-09 делает публикации неизменяемыми и сохраняет адресное сообщение исправления.

Решение: разрешить сохранённые `m8-basic-report/1.4.1` и `1.5.0` явным reader, а неизвестную версию отклонять. PDF получает одну считанную C-67 и публичный notice в той же DB-операции; рендер выполняется отдельно. Новые шаблоны `m8_participant_report_v2.typ` и `m8_report_comparison_v2.typ` сохраняют прежние `v1` неизменными. Typst работает в дочерней группе процессов с таймаутом; ошибка даёт HTTP 503 с повтором без генерации. Радар строится технической SVG-геометрией из чисел C-67, легенда и навыки печатаются Typst. Comparison PDF использует только разрешённые строки для двухсерийного радара; остальные строки сохраняются раздельно с причиной. Исходный пакет C-67, Results, схемы и права не меняются.

Границы: без новой оценки/LLM, без target-role/gap/group report, без изменения старого PDF-файла после его скачивания. Новые PDF-шаблоны версионированы в существующем контуре; предметный пакет и опубликованные `v1` не меняются. Откат — revert приложения и новых PDF-шаблонов: C-67/Results остаются неизменными. При откате сохранить чтение указателя REPORT-09.

Стоп-условия рабочего цикла: смысл сущностей/PM, публичный API, схема/миграция, источник предметного значения, новый контур артефакта, права, откат, выход за область — **нет**; основание выше и проверка изменённых потребителей. Человеческая приёмка готового PDF остаётся владельцу.

План проверки: real PDF bytes/text и шесть визуальных сценариев; unit и HTTP/integration с отказом и retry; backend набор; `git diff --check`, release/build, CI точного PR head.
