# ART-01: версионируемый промпт лаборатории M5

## Результат и область

Начальное предъявление M5 использует самостоятельный файловый prompt-пакет.
Текст и версия `m5-lab-v1` сохраняются без изменений; старые снимки исполняются
без доступа к текущему пакету. Неполный/повреждённый пакет явно блокирует новый запуск.
Включено: пакет, загрузчик, snapshot, повтор запроса, unit/HTTP/DB-проверки.
Не входит: изменение методологии, допуска Case, UI, схемы БД, реальный LLM и деплой.

## Контекст и решения

Основание: пользователь одобрил следующий шаг плана, ART-01. Тикет не предоставлен.
PM-03, синтетическая лаборатория M5; LU отдельно не утверждена.
Архитектура: Product 4K context 1.0, Registry, ADR-001 и assessment-runtime.md.
Источник текста: `Api/m5_generation_lab.py:SYSTEM_PROMPT` из commit
`c035e833236bea4c3dbc572446a0aa7aad036571`. Это существующая лабораторная инструкция,
не вновь утверждённая норма M5. Пакет имеет статус draft и область laboratory_only.
Владелец содержания — владелец M5; конкретное ответственное лицо не назначено.

Прослеживаемость: ART-01 → файловый prompt/manifest → build_generation_input →
input_json.prompt → generate → unit, HTTP и изолированный DB-тест M5.

## Ограничения и план

1. Зафиксировать исходный текст и manifest; добавить проверку перед новым запуском.
2. Проверить отсутствие fallback, сохранение снимка и повтор запросов.
3. Выполнить обязательные проверки и обновить реестр долга.

API расширяется только метаданными prompt; прежние text/version/checksum сохраняются.
Старые снимки не мигрируют. Повтор существующего run_id проверяет владельца и
request_checksum до чтения файлов. Конкурентная вставка сохраняет ON CONFLICT.
При недоступности пакета новый POST получает 503 с фиксированным кодом ошибки;
файловые пути и содержимое исключения не раскрываются.

## Критерии приёмки

- Текст совпадает с исходным SHA-256, включая пробелы и окончания строк.
- Новый снимок содержит текст, версию, checksum и происхождение пакета.
- Отсутствующий, пустой, повреждённый пакет не подменяется встроенным текстом.
- Сохранённый снимок исполняется при замене/удалении текущего пакета.
- Повтор run_id возвращает сохранённую запись без нового чтения пакета/LLM.
- Прежние HTTP-проверки полномочий и неизменяемость записей сохраняются.

## Проверки и откат

Unit и HTTP с подставным gateway, DB-тест на отдельной временной PostgreSQL с test
в имени; обязательные lint/build/backend/diff. Реальный LLM не требуется для
доказательства идентичности текста и выбора источника.
Откат — предыдущий код приложения; добавленные поля snapshot совместимы с ним.
Пакет развёртывается вместе с кодом штатным Git/CI-процессом. Новых env нет.
Исторические снимки и результаты не изменяются.
