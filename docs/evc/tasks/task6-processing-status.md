# Задание 6. Состояние обработки ответа и итогового отчёта

Основание — постановка пользователя от 27.11.2026. База — актуальный
`origin/main` (`026576a0`), ветка `codex/task6-processing-status`.

## План

1. Подтвердить этап по данным текущего Cycle, AS и C-45. Передать минимальное представление владельцу и в проекцию точного назначения.
2. Обновить интервью, состояние отчёта и существующие поверхности администратора.
3. Проверить два сбоя M6 и отделить их от сбоя отчёта на изолированной PostgreSQL с управляемым шлюзом. Проверить тексты и действия в Chromium. Приложить сравнение к PR.

Использованы [ADR-002](../../adr/002-cycle-as-dialogue-contracts.md), [контракт M8](../../architecture/product-4k/m8-results-report-contract.md), [реестр решений](../decision-register.md) и [матрица проверок](../verification-matrix.md). Для синтетической проверки применена граница `SYN-CONTOUR-OWNERSHIP`. PM-05–PM-07 сохраняют свои входы, результаты и права. Схема и предметные артефакты не меняются.

Откат — revert PR, сохранённые ходы, результаты и отчёты не требуют преобразования.

изолированной PostgreSQL. Для воспроизведения старого интервью восстановлена
квитанция исходной вкладки. Для второго назначения в браузерном стенде выбрана
его проекция из того же ответа реестра.

## Повторная проверка назначения №33

Два независимых прогона начали с назначения №33 в новой синтетической базе.
В одном прогоне управляемый шлюз вызвал `M6_EVIDENCE_FAILED`, в другом —
`M6_ASSESSMENT_FAILED`. Участник сохранил ровно один ход. Тексты ниже считаны
из собранного интерфейса Chromium для обоих запусков.

| Поверхность | Сбой обработки ответа · №33 | Сбой отчёта после закрытия сбора · №34 |
| --- | --- | --- |
| Экран участника | Ответ сохранён, но обработать его не удалось. Отправлять ответ повторно не нужно. Обратитесь к администратору оценки. | Прохождение завершено. Не удалось сформировать итоговый отчёт. |
| Строка администратора | «Не удалось обработать ответ участника» и «Завершено 0 из 8 ситуаций.» | «Не удалось сформировать итоговый отчёт» |
| Заголовок подробностей | Не удалось обработать ответ участника | Не удалось сформировать итоговый отчёт |
| Пояснение в подробностях | Ответ сохранён. Прохождение остановилось на обработке ответа в текущей ситуации | Сбор ответов завершён. Ошибка возникла при подготовке отчёта |

Первое нажатие «Проверить состояние» прочитало ту же ошибку. Повторное чтение
сохранило ход, задачу подготовки, числа запросов и попыток M6 и число решений
M7. После контролируемого восстановления сервер подтвердил `NO_QUESTION`.
Следующее нажатие убрало ошибку с обоих экранов. Участник получил доступную
кнопку «Завершить ситуацию». У администратора появилось «Оценка выполняется»,
а окно ошибки закрылось. Строка прогресса сохранила текст «Завершено 0 из 8 ситуаций.»
В базе и интерфейсе остался один и тот же ответ. Отдельное назначение №34
продолжило показывать отказ отчёта.

Повторный прогон: 2 интеграционных проверки и 3 проверки Chromium прошли.
При заданном `TASK6_BROWSER_EVIDENCE` сохраняются снимки и считанные из DOM
тексты каждого прогона. Синтетический Chromium использует проекции реальных
HTTP-ответов до и после восстановления.
