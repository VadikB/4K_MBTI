# ADM-VIS-03 · Список и добавление участников

## Результат и область

В кабинете администратора организации ручная форма содержит Email, ФИО, должность и кнопку «Добавить». Импорт списка раскрывается отдельно. В заголовке списка доступен фильтр обращений со счётчиком и возвратом ко всем участникам. Пакетные команды используют выбранные строки и допуск каждого действия. Причины недоступности выводятся у соответствующих действий.

Изменение относится к интерфейсу администратора организации и обработке ошибки строки в действующем CSV-импорте. Импорт пропускает некорректный Email по штатному контракту результата и продолжает обработку файла.

### Локальная доработка от `9d98e284`

- Отметка «Есть обращение» открывает раздел обращений в карточке, сохраняет счётчик и принимает фокус после закрытия.
- «Импорт списка» раскрывается под ручной формой. Шаблон `web/assets/templates/participants.csv` содержит `Email,ФИО,Должность`. После выбора видны имя файла и доступная кнопка «Загрузить». Результат и ошибки показаны в раскрытом блоке. Действующие алиасы колонок поддерживаются.
- Для нового участника с двумя доступными операциями показывается «Пригласить», назначение доступно в меню. При активном отправленном приглашении без оценки показывается «Назначить оценку», допустимые повтор и отзыв открываются из меню. При назначении без приглашения показывается «Пригласить», допустимая отмена доступна в меню. Зарегистрированный участник без назначения получает «Назначить оценку».
- Неопределённая отправка проверяется штатной командой «Проверить отправку». При сбое подготовки применяется ADM-VIS-02, с проверкой состояния в строке и допустимой отменой в карточке. Пакетные условия и серверные допуски используются по-прежнему.

## Воспроизведение

Используйте отдельный локальный PostgreSQL и зависимости из [инструкции Chromium](../../../../tests/browser/README.md). Сценарий открывает штатное приложение под синтетическим администратором и запускает операции через HTTP. Почтовый адаптер заменён локальным приёмником. В изолированном стенде к двум организациям допущен один синтетический администратор для проверки переключения.

```sh
npm run lint:js
npm run build:web
git diff --exit-code HEAD -- web/dist
node --test tests/frontend/*.test.mjs
npm run test:browser -- tests/browser/adm-vis-03.spec.mjs
```

Для пошагового просмотра запустите последний тест с `--debug`. Сценарии идут по порядку.

| Сценарий | Действия |
| --- | --- |
| Пустой список и фильтр | В «Участниках оценки» выберите «Синтетическая организация без программы». Откройте «С обращениями» и вернитесь через «Все участники». |
| Один участник и валидация | Введите некорректный Email и отправьте форму клавишей Enter. Затем введите корректный Email, ФИО и должность. После добавления раскройте «Приглашение и назначение недоступны» в строке. |
| CSV | Раскройте «Импорт списка», скачайте шаблон, добавьте строку и выберите файл. Сверьте имя, нажмите «Загрузить» и проверьте результат. Повторите с некорректным Email и с заголовками `email,full_name,role_description,job_instructions`. |
| Данные для назначения и приглашения | Переключитесь на основную организацию. Раскройте «Назначение недоступно», затем откройте данные организации. Вернитесь в список и нажмите «Пригласить» у нового участника. Сверьте отказ в строке и переход к сведениям. |
| Обращение | После подготовки подтверждённых данных включите «С обращениями · 1», откройте «Есть обращение». Escape возвращает фокус на отметку. Повторите на ширинах 1440, 390 и 320 CSS px. |
| Смешанные строки | На этих же трёх ширинах сравните нового, приглашённого, назначенного без письма и зарегистрированного без назначения. Откройте меню с клавиатуры, перемещайтесь стрелками и закройте Escape. Отдельно проверьте неопределённую отправку и сбой подготовки. |
| Пакетные команды | В полном списке отметьте нового участника, автора обращения с уже назначенной оценкой и зарегистрированного участника. Сверьте получателей каждой команды. Уточнение рядом с кнопкой показывает число подходящих выбранных строк. |

Для эталона выполните `python3 -m http.server 8765 --bind 127.0.0.1 --directory reference` в распакованном архиве. Откройте `http://127.0.0.1:8765/screens/index.html?scene=people`, затем смените `scene` на `issues`, `preparation` и `menu-sent`.
