## Совместимость и откат

Изменение схемы только additive и идемпотентное. Backfill сохраняет текущий состав,
включая admins. Старый код не понимает явное исключение admin из участия и может
включить его снова; поэтому rollback требует сначала восстановить участие явно либо
сохранить новый код чтения состояния. Простые revert/drop поля не считаются безопасным
откатом. Постоянная миграция требует отдельного допуска выпуска.
