## Откат

Для новых Cycle можно вернуть выбор предыдущего пакета в manifest. Опубликованные пакеты и закреплённые зависимости обеих версий остаются доступны воркерам до завершения соответствующих Cycle. Сохранённые AS читаются по их снимкам. Смена версии приложения и удаление или обновление исторических данных для локального кандидата не требуются.

## Реализация

- Пакет `m5-functional-passport@2.0.0` содержит `case-content-contract.json` и рабочий протокол Tester 2.1.0. SHA-256 обоих файлов входит в manifest пакета. Цикл закрепляет пакет, подготовка фиксирует план проверок и передаёт адресные критерии в каждый запрос Tester и Challenger для соответствующего `check_id`.
- Общий предмет, требования заказчика, преимущество A и границы B проверяются по P00 и M01–M06. Нужные определения помещаются в открытый текст P00. Для K1.I09 валидатор требует отдельное непустое поле «Что сохранить при адаптации» рядом с «Конкретным условием». Дескриптор K1.I09 читается из закреплённой M2 и остаётся во входе подготовки. Оба поля карты сохраняются в служебной допущенной AS.
- При структурном дефекте или блокирующей находке repair получает исходную AS и пути. Детерминированная проверка и оба рецензента перепроверяют AS с новым checksum. При совпадении checksum сохраняется отказ исходного кандидата. Пустые пути в находке дают ошибку протокола.
- Для SPEC.02 сохраняются 33 упорядоченные проверки, включая три точки приёмки, и 9 целей паспорта. Для SPEC.03 сохранены критерии паспортного пути задачи 01. При выборе старого пакета Cycle получает форму AS и протокол своей версии.

## Приёмка

Исправление кредитного варианта проходит новый допуск. Вариант приборов с сохраняющимся конфликтом отклоняется после повторной проверки.

- AC-3 проходит структурную проверку и допускается с заданными ответами PASS. Из проверенного кандидата компилируются вводная со словарём и шесть стартовых источников. Обе отрицательные проверки имитируют выводы рецензентов. Результат подтверждает исполнение протокола и допуска по этим ответам.
- `tests/unit/test_m5_spec02_professional_content.py` сохраняет точные запросы, ответы заглушки и итоговые checksum в pytest `tmp_path`. Контролируются неизменный порядок check_id, обе стадии допуска и равенство дескриптора данным M2.
- `npm run test:backend` — 1334 PASS. Адресный PostgreSQL/HTTP-набор — 32 PASS, включая первый старт SPEC.02 и Next, сохранение закрытой диагностики и закреплённого профиля, исторические версии и восстановление очереди. `scripts/build_m5_functional_package.py --verify-only` и dry run `scripts/plan_specialist_program_release.py` — PASS.
