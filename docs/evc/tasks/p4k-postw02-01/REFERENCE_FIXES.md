## Какие отличия от demo сохранены и почему

Точный эталонe44fa78 используется для композиции. В task01 rev1.1 прямо задан
приоритет ТЗ/общих принятых токенов для прочих цветов. В ходе исправления найден и
полностью прочитан **P4K_UI_Baseline_1.2.txt**, первичный справочник пакета отчётов:
он заменяет палитру1.1 и прямо задаёт нейтральную поверхность#F7F9FB и footer#68777C.
Путь/хеш/редакция зафиксированы в identity.json. Первичный PDF палитры заново не
проверялся; его hash и область применения указаны самим справочником.

Поэтому прежние два открытых token observations закрыты как KEEP: фон статуса
и hover вторичной кнопки используют принятый --control-bg, текст подвала — существующий
graphite600. Самостоятельные #FAFAFA/#64748B из demo не введены. Прямые более поздние
контрольные значения task01 (#F7F7F7/#464554/#CBD5E1/#18B8C6/#007D89) сохранены;
hover/active уже имелись в shared participant tokens и были приняты W02.

Реальные user menu/выход, строка версии, внутренние маршруты и права продукта
сохраняются; Прототип, demo-аккаунт и меню сцен не переносятся. PDF/compare не добавлены.
У исходного reference result есть compare-кнопки. Его обычный PNG сохранён без
изменений; для числового сравнения DOM после снимка удалены только эти неподдержанные
кнопки. Это отражено в JSON supportedReference и не выдаётся за исходный рендер.
