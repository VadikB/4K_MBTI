# Задание 2 · Допуск к старту для рецензирования M5 v7

База `origin/main` — `3ceec3490901483d75fbbba14efcd0b5b28bcc1e`.
Область поручения включает отдельную ветку, PR и синтетический прогон.
Версия приложения, merge, развёртывание и публикация артефактов за рамками поручения.

Источники — [манифест выпуска 2.0](../../../assessment_definitions/planning/specialist_pilot_release/2.0/manifest.json),
[закреплённый протокол 3.3.0](../../../assessment_definitions/prompts/m5_functional_passport/v7/tester-protocol.json),
[план применимости](../../../Api/m5_battery_review.py) и [проверка старта](../../../Api/assessment_start_readiness.py).
PM-03 формирует и проверяет AS. При старте M7 читает сохранённый результат по тому же
CaseVersion, пакету и кандидату. Планы, паспорта и тексты рецензентов не менялись.

| Контроль | До | После |
| --- | --- | --- |
| Полные трассы девяти CaseVersion | M5 `PASS`, M7 `PILOT_PLAN_REQUIRED_CHECKS_MISSING` для 9 из 9 | 9 из 9 приняты. SPEC.02 — 22/22, SPEC.03 — 21/21 для Challenger |
| Редакционное замечание Challenger | M5 `PASS_WITH_WARNINGS`, M7 пересчитывал `PASS` и выдавал `PILOT_PLAN_AS_NOT_ADMITTED` | Обе стадии сохраняют `PASS_WITH_WARNINGS` |
| Неполные, повторные и чужие результаты | Отказ | Отказ при пропуске, повторе, чужом ID, операции, роли, версии, SHA и старом раунде после repair |

M5 и M7 используют один выбор критериев по версии протокола. Для допуска M7
восстанавливает применимость из закреплённого пакета и CaseVersion каталога.
Состав отправок и результатов сверяется целиком для каждой роли. Допуск
пересчитывается по двум независимым наборам и детерминированной проверке.
Хранимый формат позволяет читать существующие трассы без вызова модели.

Регрессия обычного назначения использует локальную публикацию `specialist_pilot@2.0`
и `specialist-pilot@1.4.4`, штатные HTTP-операции анкеты, назначения, знакомства,
подготовки, старта и чтения. Локальный Chromium открыл кнопку «Приступить к оценке»,
первую рабочую карточку и ту же AS при повторном входе. Проверка в PostgreSQL
подтвердила один Cycle, один интервал сбора и сохранение первого `started_at`.
Управляемый `V04Gateway` подставлял только ответы генератора, Tester и Challenger.
Штатный TEST не использовался для прогона или выпуска.

Локальные проверки прошли — 1476 backend-тестов, 33 интеграционных теста,
линтер и frontend-тесты. Полный CI запускается после перевода PR в Ready.

Откат возможен отменой этого коммита. Миграции и правка сохранённых трасс не требуются.
