# Задание 03 · Выпуск «Пилот 4К · 9 кейсов» 2.0 на TEST

Владелец поручил опубликовать общий каталог `specialist-pilot@1.4.4` и
программу `specialist_pilot@2.0` через уполномоченного издателя. Область
поручения включает ветку, PR, следующий PATCH, слияние по обязательному CI,
автоматическое развёртывание и публикацию данных на TEST. Подключение
организаций, назначения, старт оценки и PROD находятся вне области задания.

Исходный ZIP закреплён в [манифесте выпуска](../../../assessment_definitions/planning/specialist_pilot_release/2.0/manifest.json).
Точное предложение M7 включено с исходной контрольной суммой и полями
решений в полученном виде. Выпуск проверяет банк `0.8-pilot.1`, девять
CaseVersion, правила `1.7.1`, сценарий `1.8.4`, пакет рецензентов `7.0.0`,
опубликованную методологию и совместимость конфигурации. Маршрут проверяется
для профилей с подтверждённым мандатом и без него. Идентификаторы и SHA
каталога вычисляются в целевой БД.

На сервере TEST из развёрнутого checkout:

```sh
.venv/bin/python -m scripts.release_specialist_pilot --publisher-user-id <ID>
```

Команда выполняется под служебным аккаунтом развёртывания. ID указывает на
учётную запись издателя с правом `configuration.publish`. Сохраняются
служебный principal, ID издателя, время БД и ссылки на исходные версии.
Каталог, конфигурация и ProgramDefinition фиксируются одной транзакцией.
Повтор проверяет закреплённые версии и возвращает те же ID, а расхождение
содержания прерывает транзакцию. Код использует каталог и снимок плана для
проверки допуска при дальнейшем запуске. Проверки сгенерированной AS и
данные прежних версий сохраняются.

Проверки до слияния включают существующие backend- и integration-наборы
и адресную регрессию публикации с пустыми формами, отказа при изменённом
файле или отсутствии права, повторного выпуска и чтения начатого Cycle.
После развёртывания проверяются БД, список API и раскрытый селектор. При
ошибке публикации транзакция откатывается. Прежние программы остаются
доступны для будущего выбора, а начатые оценки сохраняют закреплённые
версии. Откат кода после записи программы требует сохранения поддержки
её опубликованного контракта.
