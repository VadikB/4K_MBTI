неизменяемый индекс уже созданных доказательств по FIX-B01–B03 и ARCH-A01–A07.

публикация draft-пакетов, изменение program revision, методологии или поведения

## Прослеживаемость и границы утверждений

Источник/карточка → локальная задача ARCH/FIX → squash PR → merge commit →
тесты/первичная трасса → строка `status-matrix.json`. `PASS` в пакете означает
только область, названную в `evidence_scope`; `NOT_RUN` нельзя интерпретировать
как PASS. A06 сохраняет 27 строк матрицы `NOT_RUN` для полного real-provider
runtime до M8, хотя controlled generation/tester/admission и публичный HTTP
контракт проверены.

## Проверка и откат

Локальный минимум: проверка JSON, существования всех относительных путей,
контрольных сумм, `git diff --check`; для docs-only результата поведенческие тесты
не повторяются, а фиксируются уже выполненные точные прогоны и CI. Откат — revert
одного документационного commit; продукт, БД и опубликованные артефакты не меняются.

Фактически: JSON/path/SHA-256/`git diff --check` — PASS; адресные unit-регрессии —
`33 passed`. Pytest не смог создать только `.pytest_cache` в управляемом worktree;
это не повлияло на выполнение тестов и не является продуктовой ошибкой.
