## Границы приёмки и передача

- При отсутствии отдельного серверного события деактивации или восстановления
  журнал показывает подтверждённые записи, а карточка и результат операции —
  фактическое состояние. `updated_at` может относиться к редактированию карточки.
  История переходов с датами и авторами потребует согласования места хранения.
- Полный CI, release gate и развёртывание — NOT_RUN. Ветка остаётся локальной,
  версия продукта унаследована от 02. После принятия 02 ответственный за выпуск
  переносит проверенный diff 04 на актуальную базу, повторяет нужные проверки
  и ведёт CI на точном SHA кандидата по отдельному поручению.
- Действующие контракты записи и схема сохранены. Проверки обходятся
  синтетическими данными без доступа к реальным LLM и почте.
- Открытых решений для локального результата нет. Откат — `git revert` рабочего
  коммита 04. Для ранее деактивированной организации используется штатное
  восстановление с действующими правами. При физическом удалении действуют
  ограничения восстановления и квитанции ADR-003.
