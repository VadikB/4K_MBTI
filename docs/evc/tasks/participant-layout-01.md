# PARTICIPANT-LAYOUT-01 — экран ожидания участника

## Основание и границы

Задание `P4K_PARTICIPANT_LAYOUT_01_2026-10-31 (1).txt`. Изменение перенесено
поверх актуального `main` commit `6026820`; ранее подготовленный commit `c5abc5e`
проверен на совместимость, готовое исправление не переписывалось заново.
Меняется только панель `auth-complete`; правила readiness, назначения, переходы,
данные, права и методология не меняются.

Причина дефекта — сочетание общего `.panel { flex: 1 0 auto; }` с локальной
шириной 520px. `min-height: auto` не отменяло flex-grow, поэтому короткое состояние
растягивалось по высоте и сохраняло мобильную ширину на desktop.

## Исправление

- локально задано `flex: 0 0 auto`, без изменения общего `.panel`;
- desktop-панель ограничена 760px и использует двухколоночный информационный блок;
- действия собраны в отдельную двухколоночную строку;
- при ширине до 520px панель и действия переходят в одну колонку;
- тексты, кнопки, server-owned readiness и logout сохранены.
