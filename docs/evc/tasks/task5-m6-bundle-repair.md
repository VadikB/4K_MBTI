# Задание 5 · Ошибки цитат и пропущенные цели в одном повторе M6

## Результат

Единственный штатный повтор M6 Evidence передаёт ошибки цитат и точные `indicator_id`, пропущенные в читаемом `bundles`. Цели берутся из закреплённого входа. Запрос просит сохранить корректные фрагменты, свидетельства, записи по индикаторам и их связи. Полный ответ проходит прежнюю проверку доказательной цепочки и состава целей.

База `5d42abc2` (`main`, 2.1.88) включает [адресный повтор №307](https://github.com/VadikB/4K_MBTI/pull/307) и [контракт цитат №305](https://github.com/VadikB/4K_MBTI/pull/305). Для `1.0.1` координаты сверяются с исходным ходом. Для `1.0.2` их вычисляет сервер, а повтор проходит проверку сохранения основания из №305. Prompt, схема и хеш закреплённого запроса совпадают с базой. Хеш `1.0.1` — `1b75e29673da38ed2fbb1a3167b9fc49f54ddee514fc38f7744a2efe02239620`.

Методология требует по записи на индикатор и прослеживаемое обоснование, в том числе при `evidence_ids=[]`. Основания контрольных ответов относятся к вымышленному ходу «Сверю сроки. Уточню цену.». Две цитаты подтверждают, какие действия участник назвал. Остальные семь записей указывают конкретное отсутствующее проявление в условиях ситуации. [M6 v1.8, §§ 5.1 и 9.3](../../methodology/source-sets/2026-10-01/derived/M6-v1.8.md)

## Сохранение проверенной цепочки в PR №308

На `6ef0ce00` приложенный `test_pr308_repair_continuity.py` дал 3 passed, 3 failed. Подмена дословной цитаты прошла в `1.0.1` и `1.0.2`, а удаление цепочки без пересмотра прошло в `1.0.1`. На исправлении те же шесть контролей проходят.

Из первого отклонённого ответа сохраняются технически проверенные цепочки от Fragment через Signal до Evidence. Сервер использует штатные проверки версии, включая координаты, источник, контекст, критерий и связи. Пропущенный Bundle сам по себе допускает исправление состава ответа. При подмене повтор отклоняется с путём изменённого поля, например `fragments.0.quote`, `signals.0.observation` или `evidence.0.indicator_id`. При удалении путь указывает на `id` записи в первом ответе. Полная проверка исправленного анализа сохраняется.

Правила №305 действуют для обоснованного пересмотра. `irrelevant` с объяснением и ссылкой на исходный ход разрешает убрать основание. При `unclear` цитата и наблюдение сохраняются. Ссылка на другой ход и удаление наблюдения при `unclear` отклоняются. Повтор с 0/9 по-прежнему может принять полный ответ 9/9 за два вызова.

Корректную сводку можно обновить при новом валидном свидетельстве или при обоснованном пересмотре по №305 со ссылкой на исходный ход. Копия свидетельства с другим ID нового основания не даёт.
