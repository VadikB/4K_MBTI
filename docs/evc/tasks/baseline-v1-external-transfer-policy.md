# Запрет внешнего переноса ответов перед baseline 1

## Результат

Экран оценивания запрещает копирование текста вопросов и вставку либо
перетаскивание готовых ответов, если оператор явно не разрешил это настройкой.

## Область

- Включено: безопасное значение по умолчанию, конфигурация frontend и примеры
  `.env`.
- Не входит: прокрутка и размеры области кейса, методология, данные сессий и
  контракты агентов.

## Ограничения и риски

- Публичный API и схема базы данных не меняются.
- Разрешение переноса остаётся доступно через явное значение
  `ASSESSMENT_EXTERNAL_ANSWER_TRANSFER_ENABLED=true`.
- Настройка не является средством защиты от всех способов переноса информации;
  она задаёт проверяемое поведение интерфейса оценивания.

## Критерии приёмки

- [x] При отсутствующей переменной backend публикует значение `false`.
- [x] При недоступном runtime-конфиге frontend также запрещает перенос.
- [x] Все примеры окружения фиксируют запрет как исходную настройку.
- [x] Явное значение `true` по-прежнему разрешает перенос.

## План проверки

- Регрессионные unit-тесты значений по умолчанию и явного разрешения.
- `npm run lint:js`, `npm run build:web`, `npm run test:backend`.
- После deploy — ручная проверка copy/paste на test-стенде.

## Откат

Установить `ASSESSMENT_EXTERNAL_ANSWER_TRANSFER_ENABLED=true` и перезапустить
приложение либо отменить commit без миграции данных.

## Передача результата агентом

  backend и frontend.
- Изменены `Api/config.py`, `web/js/config.js`, примеры окружения, `README.md`
  и регрессионный тест конфигурации.
- Пройдены два целевых теста, `npm run lint:js`, `npm run build:web`,
