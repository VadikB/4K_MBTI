# Канонический пакет методологии 4К 1.1

## Результат

Исходные паспорта и матрицы M2 преобразуются в детерминированный draft-пакет
методологии 4К 1.1. Пакет выражает иерархию
`Competency → Skill → Component → Indicator`, дескрипторы `L0–L3`, Evidence
Patterns, границы и Red Flags и проверяется без обращения к БД или LLM.

## Область

- Включено: schema v2, конвертер DOCX/XLSX, семантическая валидация,
  контрольные суммы, сгенерированный draft-пакет и модульные тесты.
- Не входит: публикация версии, изменение default configuration, миграция БД,
  evaluator contract v2, связь кейсов с Indicators, роли и агрегация уровней.

## Контекст

- Архитектура: `docs/adr/001-assessment-platform-architecture.md`.
- Runtime: `docs/architecture/assessment-runtime.md`.
- Исходники: восемь нормативных файлов M2, переданных вне репозитория.
- Все файлы трактуются как Methodology 4К 1.1 независимо от версии в имени.

## Ограничения и риски

- Опубликованная методология 1.0 и её табличный bundle не изменяются.
- Идентификаторы M2 сохраняются дословно; пропуски не перенумеровываются.
- `L0` не смешивается с отсутствием Evidence.
- Компонент может не иметь отдельного определения, если паспорт содержит только
  компактную карту; текст не синтезируется конвертером.
- Исходные Office-файлы не копируются в Git; manifest хранит имя и SHA-256.

## Критерии приёмки

- [x] Пакет содержит 4 Competencies, 14 Skills, 35 Components и 61 Indicators.
- [x] Каждый Indicator имеет ровно `L0`, `L1`, `L2`, `L3`.
- [x] Все parent-ссылки существуют и согласованы.
- [x] Evidence Pattern присутствует у каждого Indicator.
- [x] Повторный запуск на одинаковых источниках даёт одинаковые файлы и checksum.
- [x] Пакет имеет статус `draft` и не может стать default автоматически.

## План проверки

- Модульные тесты парсера и семантического валидатора.
- Два запуска конвертера с сравнением результата.
- Стандартные проверки репозитория перед передачей.

## Откат

Удалить новые schema, скрипт, тесты, документацию и каталог draft-пакета. База,
runtime и опубликованные определения не затрагиваются.
