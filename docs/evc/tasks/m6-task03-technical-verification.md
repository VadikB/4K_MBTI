## Результат

Завершено. Добавлено 11 integration-проверок в
`tests/integration/test_m6_evidence_db.py`: девять параметризованных вариантов
из задачи 2, один timeout/retry, один процессный exit/recovery.
Runtime и схема не менялись; хеши пакета задачи 2 остались прежними.

Девять кандидатов проходят через сохранённый C-45 → resolver → enqueue → worker
со stub gateway → PostgreSQL revision/bundles → read_analysis. Проверены точные
Turns, материалы, targets, полный output и сохранённый input; девять EB на AS,
одна попытка после повторного worker-вызова. UUID/ссылки AS/Cycle/Session привязаны
к созданным в isolated DB snapshots, синтетическая запись Dialogue переносится
в C-45. Это проверка потребителя, **не проверка того, как M5 исполнил сценарий**.
Draft output заранее задан; смысловая атрибуция и самостоятельность не утверждаются.

Timeout инъецирован исключением gateway, без сетевого провайдера: failed attempt,
ноль revisions/EB; после успешного retry две сохранённые попытки и один результат.
Реальный сетевой timeout по-прежнему NOT_RUN.

Отдельный дочерний процесс действительно завершён через `os._exit(73)` после
commit claim, до сохранения результата. После управляемого истечения lease
новая попытка создаёт единственный результат; статусы попыток expired/succeeded.
Это не проверка сбоя сервера PostgreSQL или произвольной точки power-loss.

## Дополнительный review после команды «идем дальше»

   связанного BS/Evidence. Теперь граница BS — sequence его Fragment, граница Evidence —
   последний из его Fragments. Более поздняя ссылка даёт `M6_CONTEXT_FUTURE`;
   ссылка на отсутствующий объект остаётся `M6_CONTEXT_REFERENCE`.

Turn остаётся кандидатом для экспертного рассмотрения, но draft цепочка больше не
ссылается на раскрытые позже D1/D3. Manifest hashes обновлены. Добавлены регрессии
