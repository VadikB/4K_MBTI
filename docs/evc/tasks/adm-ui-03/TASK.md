# ADM-UI-03 · Обращения и ответ в кабинете

## Результат и область

Отметка в строке участника открывает раздел обращений в карточке ADM-UI-01.
Фильтр организации использует серверный счётчик. В карточке доступны исходное
сообщение, подтверждённый статус, действие по состоянию и сохранённый ответ.
В «Моих оценках» видны собственный ответ, разрешённое имя автора и время.
Контакт администратора остаётся самостоятельным действием.

может содержать только часть ссылки. Для такой записи название опускается.

Применены AGENTS, README, CONTRIBUTING, рабочий цикл EVC, матрица, рецепт

Стоп-условий рабочего цикла нет. Смысл сущностей, публичный контракт, владельцы

## Как открыть

1. В синтетической организации войти администратором и открыть «Участники оценки».
   Нажать «С обращениями». Повторное нажатие возвращает весь список. Для пустого
   состояния включить фильтр в организации без сохранённых обращений.
2. На строке нужного человека нажать «Есть обращение» или «Обращения · N».
   Раздел «Обращения участника» получает фокус. Для входа сверху открыть ту
   же карточку нажатием имени. Esc возвращает фокус на использованную кнопку.
3. Для нового обращения нажать «Взять в работу», заполнить «Ответ участнику»
   и отправить. После сохранения карточка показывает «Ответ отправлен».
4. В новой сессии этого участника открыть «Мои оценки». Блок «Ответ по вашему
   обращению» содержит сохранённый текст, автора и время. «Ваше обращение»
   раскрывает исходное сообщение. Кнопка связи открывает отдельный контакт.
5. Сценарий потери ответа воспроизводит `admin-appeals-live.mjs`. Он прерывает
   первый POST до сервера и второй после сохранения, затем сверяет БД и кабинет.
