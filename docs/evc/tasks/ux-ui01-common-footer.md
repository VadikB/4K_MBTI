# UX-UI01 — единый подвал общих зон

## Результат

Один общий footer виден на самостоятельных экранах без чата, скрыт в чатах
знакомства и оценки, корректно занимает низ короткой страницы и следует после
контента длинной страницы.

## Область

- Включено: общий компонент, автоматический год, Onest, адаптивность, правило
  видимости по фактической панели, UI-спецификация и frontend-регрессия.
- Не входит: новые экраны, URL документов без согласованной конфигурации, изменение
  согласий, чатов, оценки, API, данных, прав, палитры или иных задач очереди.
