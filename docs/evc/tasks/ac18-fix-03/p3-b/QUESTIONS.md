# Открытые вопросы и зависимости

- Для 200% текста на 390 px общий topbar и `textarea` выходят за viewport
  (543 px). Исправление относится к мобильному слою 3А; передать измерение
  и PNG исполнителю 3А через согласованный канал. Это не PASS визуального AC10.
- Для публикации кандидата нужны отдельные разрешения на version bump,
  branch push/PR, затем обязательный CI, human review, merge и TEST deploy.
  Локальная подготовка не заменяет эти решения.
- P3-OPS01 требует доступного TEST и самостоятельного конкретного допуска на
  проверку исторического Cycle. Синтетический PASS не означает его исправление.
