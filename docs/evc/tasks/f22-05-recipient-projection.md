# F22-05 — единая проекция получателей результата

## Результат и основание

Основание — F22-05 P1 из `P4K_Full_Verification_2026-10-22.txt`. Текст C04
сохраняется как исходный ответ заказчика, но больше не определяет сообщение участнику
о доступе. Preview, подтверждённый briefing и readiness используют безопасную
проекцию из фактического `recipient_mapping`; выбранные администраторы дополнительно
проверяются сервером.

## Источники, границы и решение

Прочитаны обязательные EVC-документы, Change 01 `1.0/01` (WORKING), task manifest
2026-10-01, `Api/questionnaire_sources.py`, `Api/acquaintance.py`, API routes и тесты.
M1 `1.4` остаётся FROZEN, CURRENT=NO. Новая методологическая норма не вводится:
это устранение противоречия между отображением и уже существующим контрактом прав.

Сервер формирует две допустимые проекции: только участник; участник и выбранные
представители заказчика. UI получает эти строки в preview и переключает будущую
проекцию по тем же controls, которые отправляются в confirm.
