## Непроверенное

Визуальная вёрстка DOCX не изменялась и не оценивалась: оригинал копируется побайтово,
цель — смысловое включение источника. Markdown сохраняет текст/таблицы, не пагинацию.

перед слиянием согласно матрице. Полнота аудита и согласованность новых M5–M8 не доказаны.
