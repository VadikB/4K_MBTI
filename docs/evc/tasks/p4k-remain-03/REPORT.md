# REMAIN_03 — отчёт исполнения

## Результат

Выполнен F15-AC01–03 в границе PM-02 invitation/readback. API возвращает отдельный исход каждого адресата; readback проверяет отправителя, организацию и оценку, показывает `delivery_status` отдельно от `link_status`, не выдумывает исход адресата без сохранённой записи. Клиент сохраняет identity операции до POST, восстанавливает её после unknown/reload и не применяет поздний ответ к другому actor/org/view. `expires_at` в JSON имеет UTC `Z`; письмо явно использует UTC, UI показывает местное время на основе серверного момента. Использованная ссылка остаётся использованной в истории, guard отзыва не ослаблен.

Синтетический mail sink подтверждает вызов отправки и идемпотентность на тестовом контуре. Реальное принятие письма внешним провайдером не проверялось. Назначение и старт оценки не запускались.

## Риски: конфиг / схема / деплой / безопасность / откат

- TTL и предметный конфиг не менялись. Пользователь согласовал выпуск patch `2.1.3`, штатный preflight обновил номер в `pyproject.toml`, `uv.lock`, `web/js/config.js`, `web/index.html` и пересобрал `web/dist`. `expires_at` теперь сериализуется с `Z`: момент совместим с ISO-8601, но клиентам, зависящим от прежней строки без смещения, нужно принять явную UTC-метку.
- Миграции и изменение схемы нет. Существующие записи/состояния delivery читаются; новые поля ответа необязательны для старых клиентов.
- Публикации/деплоя нет. Перед выпуском архитектору сверить актуальный main/контракты и обязательный CI для точного PR head.
- Readback требует права текущего отправителя на организацию, ограничен `created_by_user_id`, assignment и operation; неизвестный адресат остаётся `uncertain`. Локальное хранилище несёт только ключ scope и email адресатов, как существующий админский UI; при невозможности надёжно записать identity команда не отправляется.
- Откат разработки: revert кодового commit и пересборка `web/dist`; уже созданные записи приглашений/операций не удалять. При выпуске откат совместимого API/UI изменения требует проверки текущих клиентов на формат UTC.
