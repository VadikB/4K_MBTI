# Байтовые оригиналы и копии для просмотра

`original-audit-bytes.tar.gz` содержит полный безопасный исходный аудит с путями
относительно его папки. `audit-copy.json` хранит SHA-256 исходных байтов;
все записи проверены чтением из архива. Старый REPORT и первичные результаты
в основном checkout не изменялись. Старый worktree для доступа к ним не нужен.

`raw-log-bytes.tar.gz` сохраняет точные байты файлов, у которых машинный вывод
содержал хвостовые пробелы или пустые строки EOF. Их Git-копии предназначены для
просмотра и отличаются только этими пробелами. Исходные/просмотровые hashes
перечислены в `view-normalization.json`. Проверка git diff --check не ослаблялась.

Для проверки оригинала использовать tarfile.extractfile и SHA-256 без перезаписи
файлов. При необходимости распаковывать архив только в новый пустой каталог.
