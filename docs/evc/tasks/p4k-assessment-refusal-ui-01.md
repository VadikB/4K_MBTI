# P4K_ASSESSMENT_REFUSAL_UI_01 — причина отказа Next

Принятое пользователем исправление показывает безопасную причину отказа из
`preparation_operation.error.message` в карточке перехода PM-04/LU-04.2.
Карточка сохраняет причину при обновлении, сбое GET, reload и возврате из
«Моих оценок». Общий текст остаётся для старых ответов без причины.
Новая операция получает собственную причину и идентификатор для чтения статуса.

PM-04 использует действующую публичную проекцию Next из
[очереди подготовки](../../../Api/product_cycle_preparation_queue.py).
[Registry](../../architecture/product-4k/registry.md), Change 01, M1 v1.4

Изменяется только показ уже подтверждённых сведений. Контракт, данные и
сценарии подготовки остаются совместимыми. Сообщение выводится через textContent.
