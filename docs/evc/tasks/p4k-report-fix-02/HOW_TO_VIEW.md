# Как посмотреть REPORT-FIX-02

Из корня checkout `p4k-postw02-05` после обычной установки зависимостей:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
npm install
npm run build:web
npm run preview:reports
```

Если зависимости уже установлены и сборка готова, нужна только последняя команда.
Откройте [http://127.0.0.1:18972/__reports/](http://127.0.0.1:18972/__reports/).
Команда также печатает фактический URL и checkout SHA. Адрес `/__reports/identity`
содержит SHA-256 исходников/сборки и идентификатор своего процесса.

Занят порт: `npm run preview:reports -- --port 18974`. Другой установленный Python:
`P4K_PREVIEW_PYTHON=/полный/путь/python npm run preview:reports`.
Штатный PDF renderer — Python-пакет `typst>=0.14.8` из `requirements.txt`;
статические PDF вместо него не выдаются. Node-зависимости — из `package-lock.json`.

На меню и рамке указано «Локальный просмотр · вымышленные результаты».
Внутри рамки открывается настоящий HTML/CSS/dist этого checkout.

- **P01**: полный отчёт. «Заливка», «Контур», «Шкалы»; нажмите навык/точку,
  затем «Почему сделан такой вывод». А=0, Б=2,25, В=3.
- **P02**: 0, частичный 1,50, наблюдения без числа, отсутствие результата;
  в «Коммуникация» только две числовые оси, поэтому соединённой фигуры нет.
- **P03**: сравнение. А: 1,75→2,25, +0,50; Б: 0→0; В: 2→1,75, −0,25.
  «К отчёту», «Сравнить оценки» и reload сохраняют конкретную пару.
- **P04**: оба результата А частичные, 1,50→1,75 и +0,25; основания каждой
  стороны открываются отдельно. «Скачать сравнение PDF» вызывает серверный renderer.
- **P05**: смешанная пара. По Б изменён состав, по В полный/частичный;
  разности запрещены с причиной. Выберите другую «Предыдущую оценку» или
  «Разные роли» в рамке — результаты будут раздельными.
- **P06**: отчёт A с «Пример A: уточнил срок». Откройте «История оценок»,
  отчёт B — получите ошибку без данных A. В рамке «Успешный повтор», затем
  «Повторить» на экране — B с «Пример B: согласовал условие».
  «Отказ PDF» включает отказ для отчёта, сравнения, истории и «Список администратора».
  Снимите флажок или нажмите «Успешный повтор» и повторите скачивание той же кнопкой.

Слоты примеров привязаны к каталогу `competencies_4k/1.1` в test fixture:
А — `K1.1` «Ориентация и проектирование коммуникации»;
Б — `K1.2` «Передача смысла»;
В — `K1.3` «Слушание, реконструкция и верификация смысла другого»;
Г — `K1.4` «Согласование смыслов и позиций»;
Д — `K2.1` «Организация совместной работы».
Направления: коммуникация, командная работа, креативность, критическое мышление.
Это фиксация тестового каталога, число осей runtime берёт из сохранённого отчёта.

Остановить: **Ctrl+C** в терминале запуска. TTL — **15 минут**.
Сервер слушает только `127.0.0.1`; рабочая БД, приглашения, кейсы, LLM, почта и
настоящий TEST/Prod не используются. Проверочные процессы при передаче остановлены.
Повторный запуск той же командой воспроизводит меню.
