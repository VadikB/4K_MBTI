## Контракт и совместимость

Пакет prompts и контракт AS получили версию `2.0.0`. Контракт указывает
совместимый точный ref `1.0.0` для проверки закреплённых CaseVersion.
PM-03 строит правила выдачи из поля 17 и карты событий этого контракта.
Карта выбирается по CaseID и SHA-256 исходного паспорта, который сохраняется
при выпуске производного CaseVersion.
Модель заполняет тексты материалов, персонажей, события и связи наблюдаемости.
При наличии нескольких допустимых привязок модель связывает отложенные ID
с событиями по их условиям, а сервер проверяет однократную выдачу.

Оба запроса получают правила из одного входного снимка. PM-03 заполняет
пропущенный фиксированный список. У действия ведущего с пустой выдачей
сервер убирает корректно перечисленные стартовые ID. Несовместимые
предложения передаются в допуск с адресной диагностикой. Рецензенты получают
собранную AS. Трасса связывает ответ шлюза, принятую AS, скомпилированный
Case и правила исполнения через контрольные суммы.

Новый Cycle закрепляет `m5_functional_as` из `v2`. Первая AS и Next читают
закреплённый манифест. Cycle с `v1` продолжает подготовку на `1.0.0`, а
старый Cycle без этой зависимости использует существующий путь `v1`.
Отдельная операция в рамках уже созданного Cycle наследует его манифест.
Идемпотентное чтение готовой AS возвращает сохранённый снимок.

Повтор назначения №27 получит `2.0.0`, если подготовка на обновлённом
воркере создаст новый Cycle с `v2` либо продолжит Cycle, уже закрепивший
`v2`. Фактический манифест №27 требуется для определения его версии.

## Проверки и откат

Проверить серверную сборку и повторный допуск на искусственных ответах,
первый старт и Next через очередь и HTTP, однократную выдачу SPEC.01/M02 и
адресную SPEC.03/M04, чтение `v1`, сборку банка и backend-набор. Привязка
событий, поля AS и трасса используют существующие артефакты и хранилище.
Локальный этап использует действующие правила методологии и схему публикации.

Локальный откат возможен отдельным обратным коммитом. Для будущего отката
в контуре с начатыми `v2` Cycle
нужно сохранить пакет и совместимый обработчик `v2` для их подготовки.
