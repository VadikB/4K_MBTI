## Результат на штатном пути Dialogue

Сервер сначала проверяет целый адрес в адресованной реплике отправителя.
Доставка связывает сохранённый источник с ID хода и фактическим получателем.
Когда тот же получатель отвечает, отдельно проверяется дословная цитата из
состоявшегося ответа. Если в ответе есть адреса, в утверждающей цитате должен
быть целый адрес доставленного источника. Для ответа без адреса допускается
однозначная отсылка к той же доставленной версии. Ссылка на другую версию
вне утверждающей цитаты и другой предмет вопроса сами по себе не отменяют
подтверждение. При искажении условия первой остаётся коррекция E02_CORRECT.

| Контроль | На 1.8.2 | На 1.8.3 |
| --- | --- | --- |
| Отправлен `m5-material://M02/4`. «Открыл и прочитал актуальный фрагмент по ссылке m5-material://M02/4. Старую ссылку m5-material://M02/3 не открывал». | Доставка и ответ в журнале, фрагмент в ожидании. Без второй ссылки открытие проходит. | Одна доставка и одна подтверждающая реплика. |
| После доставки и паузы «Вы открыли m5-material://M02/3 или m5-material://M02/4?» | Ответ сохранён, открытие не записано. | Та же доставка связана с подтверждением версии 4. |
| «Сколько времени у вас есть?» — «У меня десять минут. Я уже открыл и прочитал актуальный фрагмент по m5-material://M02/4». | Фрагмент не добавлен. Тот же ответ на прямой вопрос об открытии проходит. | Сохранены уточнение E04_CLARIFY и подтверждение E01_RECEIPT в одной реплике. |
| Ошибочное указание старой актуальной версии и явное подтверждение открытия /4 | Сохранена коррекция с ответом без открытия. | Основное событие E02_CORRECT. Подтверждение E01_RECEIPT сохраняется отдельно внутри той же фактической реплики. |
| Только /3, обещание, недоступность, неопределённость, другая роль, недоставленная ссылка | Знание адресата не появляется. | Знание адресата не появляется. Если доставка была, источник остаётся в ожидании. |

До открытия в запросе R_RECIPIENT отсутствует закрытый фрагмент. После
подтверждения `context.opened_materials` содержит текст «Ручная сверка 24
записей, без проверки автозапуска», версию `4`, адрес `m5-material://M02/4`
и SHA-256 `70ace1be5b4d6f0795d2eb3b37c87b2562669eadba1acc2170905e2ac2963f0f`.
`information_transferred` содержит фактического адресата и источник.
`character_response.payload_json.opened_source` указывает ID доставки.
В состоянии хранятся идентификаторы её хода и подтверждающего хода.
Повтор каждого запроса проверяется по тем же ID. Пригодность для
подготовки и допуск к исполнению требуют собственных оснований.
