## Воспроизведение и приёмка

Тесты `test_m5_spec08_delivery_db.py` и `test_m5_battery_v04_db.py` используют
штатные подготовку AS, обработку хода, паузу и возобновление на локальной
изолированной БД. Сохраняются первые запросы, сырые ответы генератора и repair,
входы персонажа и решения сервера. При установке `M5_V04_EVIDENCE_DIR` тесты
выгружают полные синтетические перехваты. Рецензенты возвращают фикстуры PASS с
пометкой «Ответ тестового шлюза». Свежая модель и человеческий допуск — NOT_RUN.

Повтор охватывает обычную генерацию, неправильный заголовок, исправимую и
повторную копию, цитату, открытие, неподтверждённое открытие, ссылку без доступа,
устаревшую версию, другого адресата и обещание. Матрица девяти кейсов включает
письменные ответы SPEC.02 и SPEC.07 в C-45. Ранний финал прогоняется отдельно.
Возобновление проверяется для старых Cycle со сценариями `1.6.0` и `1.8.0`.

Переносимый комплект для методолога содержит два набора перехватов с указанием
SHA, форму 05 с тремя открытыми полями допуска на каждый кейс, предложение M7
на каталог `1.4.1`, открытые решения двух ролей и руководство `HANDOFF.md`.
