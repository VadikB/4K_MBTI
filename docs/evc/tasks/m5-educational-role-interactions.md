# Взаимодействия проектной роли при подготовке учебной AS

## Результат и решение

22.11.2026 владелец подтвердил передачу `interactions` всем учебным ролям для
выбора персонажей и взаимодействий в пределах паспорта кейса. Согласованный
результат относится к новым циклам. Область работы — локальная реализация и
проверка. Изменений Web, Telegram, публичного HTTP API и схемы БД нет.

  Паспорт задаёт изменяемые слоты, функции, мандат, границы и цели оценки.

  и версию роли. До изменения M4 использует привязанный базовый профиль 4К,
