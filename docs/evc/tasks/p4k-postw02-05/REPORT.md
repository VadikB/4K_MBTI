## Изменение поведения

Неотправленный текст сохраняется при input в localStorage в точной области
owner × Cycle × AS × slot. Сервер подтверждает отдельную изменяемую запись;
только тогда появляется «Черновик сохранён». GET/PUT/clear не создают Turn,
operation анализа, Evidence, профиль, Results, Report или сообщение персонажу.
Текст/переносы сохраняются дословно, предел10000 UTF-16 единиц на клиенте
соответствует действующему клиентскому ограничению отправки. Кнопка отправки
и её существующий contract/readback остаются явными. Набор символов не логируется.

Технические интервалы: debounce750ms, maxWait3000ms при непрерывном наборе;
один запрос в полёте, следующие правки объединяются. Сеть использует существующий
fetchWithDeadline. Input не ждёт сеть. pagehide лишь дополнительно пробует flush,
сохранность последних символов опирается на немедленный localStorage, а не unload.

## Область, редакция и очистка

Основной slot — dialogue:<последний сохранённый turn_id> либо dialogue:start.
ASK — clarification:<decision_id>:<question_turn_id>; сервер проверяет также
актуальный interim C54. Heartbeat/временная revision слот не меняют. Новое
назначение получает другой Cycle/AS, новая реплика — другой slot. Сервер проверяет
владельца, snapshot целостность, активное состояние, остаток бюджета, deadline
и неизменённый доступ назначения. Организационный администратор чужой draft
не читает. Восстановление выполняется после owner runtime и R1; autosave не Continue,
не heartbeat, не Pause и не продление времени. Прежнее поле при недоступности
остаётся отдельным от нового слота, не становится новым ответом автоматически.

assessment_answer_drafts хранит только текущий text/revision/version/expiry/tombstone
каждого слота. CAS serialized Cycle→AS; одинаковая revision с тем же текстом
идемпотентна, с иным — conflict. Пустой text — новая версия удаления. Запоздалая
запись не перескакивает версию/slot. Конфликт сохраняет локальный текст; простые
действия позволяют явно выбрать серверную/локальную редакцию. Разошедшиеся
локальные вкладки сохраняют альтернативы до выбора, без истории набора.

Очистка требует независимого accepted readback исходных request_id/turn_id,
проверяет именно слот отправленного Turn и revision. Новый локальный текст
не стирается старым ACK, включая равный текст с новой revision. Старый autosave
не может воскресить принятый slot. «Ответ принят» отделён от статуса draft.

## Online/offline, неизвестная отправка и logout

Подтверждённая серверная редакция читается с чистого browser context после входа.
До сети последние изменения доступны только в localStorage того же браузера,
с соответствующей подписью. При отказе storage/сети текст остаётся в DOM,
сообщение не обещает сохранение; повтор при восстановлении связи DOM не очищает.
Синхронизация не требует service worker. Фокус перепроверяет сохранённую редакцию.

Pending отправки перемещён из sessionStorage в localStorage, сохраняя прежние
request_id, turn_id, endpoint, исходную область и revision. Валидная старая pending
запись переносится после проверки владельца/идентичности; обычные legacy-drafts
без доказанного точного вопроса не подхватываются новым механизмом. Reload/закрытие
после клика сначала восстанавливают readback, а не новый Turn. Unknown/отказ сохраняют
прежний текст для копирования даже при экране обработки; автоматической отправки
и повторного LLM из механизма draft нет.

Добровольный logout предупреждает о неподтверждённом тексте до удаления локальных
копий владельца. Серверный draft остаётся до его срока. Истечение сессии локальную
копию само по себе не удаляет; чужой вход/смена identity очищают DOM. Удаление в
соседней вкладке блокирует поздний ACK от повторной записи локального текста.

Срок draft ограничен уже зафиксированным календарным deadline этого Cycle;
серверный штатный maintenance (не чаще раза в60s) удаляет просроченные строки.
Локальные drafts/pending очищаются при следующем bind после expiry и при logout;
после deadline прежняя pending не открывает новый разрешённый ответ. Удаление
аккаунта/AS распространяется FK CASCADE. Отправленные Turns и их политика не меняются.
