# ASUX-05 · Завершение и результат выбранной оценки

## Результат и граница

Карточка результата показывает адресное состояние выбранного Cycle и открывает подтверждённый Report по его ID. Завершение, ожидание, потеря связи, истечение срока и технический сбой различимы. Прогресс берётся из серверного `route_progress` сохранённого маршрута.

Основание — карточка `P4K_PR01_ASUX-05_Outcome.md` (ред. 1.1 от 20.11.2026) и автономный `P4K_ASUX_Visual_Reference_v2.html`. Прямое поручение владельца разрешает `branch_push=true`, `pr=true`, `version_bump=true`, Ready и обязательный CI. `merge=false`, `deploy=false`, `artifact_publish=false`.

База `origin/main@3cc4934c59584ed06fa8ad17f83d85fb2db6c8f9` (2.1.43), ветка `codex/asux-05-outcome`, кандидат 2.1.44. На базе браузерный сценарий выбора Б при готовом A воспроизвёл «Ваш результат готов» вместо ожидания Б.

- [Контракт обработки](../../../architecture/product-4k/m10-processing-state-contract.md) разделяет технический сбой и выдачу существующего ограниченного отчёта. Расчёт, содержимое Report и радар продолжают использовать свои контракты. Переход к конкретной версии из истории отчётов использует существующий маршрут выдачи.

## Приёмка и откат

[Матрица проверок](../../verification-matrix.md) применима к JS и HTML/CSS. Chromium использует реальный bundle, штатные маршруты и синтетические HTTP-ответы на два Cycle. SQL-проверка в изолированной PostgreSQL подтверждает знаменатели 8 и 3 после сокращения текущего каталога. Сравнение с эталоном выполнено при 1440 и 390 CSS px. SHA-256 эталона `d54795042b580643edebeb84ed90e83581c7d763466aedd3ae5ed158a66e0c92`. Результаты для актуального SHA и обязательные jobs GitHub зафиксированы в разделе «Проверка» PR.

До слияния откат ограничивается закрытием PR. Для принятого изменения достаточно revert PR и пересборки frontend. Изменений данных и миграций нет.
