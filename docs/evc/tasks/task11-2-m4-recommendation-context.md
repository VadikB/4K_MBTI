## Карта полей и детерминированное правило

Начало пути ниже — `Results.personalized_profile_snapshot.content`.
Обёртка builder с `content` и сохранённый content-only формат читаются явно.
Произвольное рекурсивное распознавание JSON, плоский legacy RoleProfile и поле
`position` не добавляются: подтверждённого исторического контракта для них нет.

| Канонический путь | Значение и применение |
| --- | --- |
| `user_context.regular_tasks` | Фактическая задача; первый кандидат |
| `role_profile.card.typical_tasks` | Типовая задача роли, если фактическая не задана |
| `role_profile.card.mission` | Миссия роли, если задачи отсутствуют |
| `role_profile.card.work_objects` | Объект работы, не полномочие (исправлено прежнее `objects_of_work`) |
| `user_context.position_or_status`, `specialization`, `unit_or_program` | Профессиональные условия; не выдуманная задача |
| `organization_context.activity_description`, `activities`, `products`, `employee_context` | Среда деятельности при отсутствии более конкретных сведений |
| `role_profile.card.independent_authority`, `approval_required`, `escalation`, `role_constraints` | Только границы практики; сохранены с путём и полным текстом в input и limitations |
| `user_context.irrelevant_areas` | Ограничение выбора, не положительный контекст |
| `user_context.systems_and_tools` | Безопасная профессиональная проекция; самостоятельно не подменяет задачу |
| identity, contacts, name, email, phone, token, metadata и прочие поля | Не включаются; вложенные словари не обходятся |

Порядок в `v1_2/templates.json.context_policy.selection_order` фиксирован;
выбирается первое непустое поле, первый текст списка. Путь, индекс, значение,
версия политики и границы сохраняются в `input.context_selection` и checksum.
Текст не обрезается посередине ограничения. Отсутствие сведений даёт `missing`
и честный fallback; неправильная структура известного поля — техническая ошибка
`M8_PROFILE_INVALID`, без включения входных значений в сообщение.

Это детерминированный **кандидат контекста**, не семантическое доказательство,
что произвольная задача подходит любому индикатору. Текст прямо требует проверить
применимость к конкретной функции и запрещает самостоятельное выполнение при
запрете/необходимости согласования. Генератор не выводит полномочия из должности.
Свободный текст правил не классифицируется моделью; автоматическая проверка
содержательной совместимости не заявляется. Неизвестные поля не угадываются.
