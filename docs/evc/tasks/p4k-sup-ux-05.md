## Стоп-условия

1. Предметный смысл и автоматический переход не меняются.
2. Новые внутренние GET только у платформенной роли по карточке. Действующие
   маршруты и DTO совместимы. Выбранная владельцем база UX-01 подтверждена.
3. Миграции и удаления нет.
4. Новых норм предметной области нет. Противоречия в источниках не выявлены.
5. Новый контур предметных артефактов не нужен.
6. Переиспользуются действующие роли, проекция содержит только безопасные поля.
   Контур и разрешённый origin берутся из конфигурации приложения.
7. Откат локального изменения удаляет добавленные GET и их клиент. Данные,
   снимки и инженерная диагностика остаются пригодными.
8. Вне области задачи находятся автоматическая передача, выпуск, изменение
   допуска и повторный запуск рабочей операции.

этого контракта не проецируются на текущего участника.

## Откат и передача

Изменений схемы, конфигурации окружения и опубликованных предметных артефактов нет.
Откат одним revert локального коммита удаляет GET и интерфейс вместе со сборкой.
Сохранённые операции, ссылки P4K в старых экранах и закрытая диагностика остаются
доступными. Производительность на большой очереди остаётся непроверенной. Список
пагинирован. Поиск по точному номеру вычисляет номер по сохранённой операции без отдельного индекса.

Для выпуска владелец отдельно разрешает PR и номер кандидата. Обязательный CI и
review проходят на точном SHA перед слиянием. Два внешних ролевых эталона требуют
доступа для парной визуальной сверки. Локальные снимки обоих ролевых экранов приложены.
