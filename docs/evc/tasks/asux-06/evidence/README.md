# Визуальная сверка ASUX-06

- Прогресс, действие и условия находятся в карточке назначения. Фактическая позиция 1, подтверждено 0 из 2, срок взят из Cycle. В истории три состояния. На узком экране блок помощи следует за карточкой оценки.
- Контакт читается целиком, почта доступна ссылкой. По Escape и «Закрыть» фокус возвращается к вызвавшей кнопке. Текст сохранённого ответа и исходное обращение доступны отдельно.
- В продукте контакту и ответу соответствует один и тот же набор синтетических данных, поэтому сохранённый ответ виден также на общем снимке кабинета. Для ответа с доступным именем показана Ольга Орлова, для исторической записи показаны роль и время. Контакт помощи в обеих сценах — Александра Соколова.
- После выхода показан штатный первый шаг парольного входа с сообщением о завершении сессии. В эталоне это демонстрационный экран возврата.
