# P4K-REPORT-03 — полнота и исходы навыка

## Результат и границы

Сохранённый Report и публичный ответ различают выполнение плана, область программы, достаточность результата навыка и техническую ошибку. Четыре исхода M6 и точные числа не меняются. Включены C-46/C-56/C-67, проекция PM-06, показ PM-07, адресные тесты и новая версия существующего пакета отчёта. Не входят перерасчёт M6, уровни Skill, полная компоновка REPORT-04/05 и сравнение REPORT-07.

Коды причины остаются машинными. Для неизвестного кода показывается безопасное общее сообщение; исходный код остаётся в сохранённом Results для диагностики. Числовая сопоставимость по навыку будет решаться в REPORT-07 с использованием включённых/отсутствующих IDs и условий, не по одному глобальному флагу.
