## Результат и решения

без IA/C-54/агрегации. [Контракт](../../architecture/m6-a-contracts.md) фиксирует
нормализованный вход C-45, resolver DB refs→UUID, Dialogue/material identity,
разные checksum contracts, frozen критерии/контекст, модель request/attempt/revision,
права и артефактный формат. [Карточка реализации](m6-a-implementation.md) задаёт
пути, этапы, миграцию, T-A1–A8 и откат. Это технические решения внутри разрешённой
подготовки, не утверждение новых методологических норм и не разрешение на выпуск.

M6/M7/M8 скопированы побайтово в SourceSet, доступны производные тексты абзацев/таблиц;
графические схемы отдельно не воспроизводились. M0 остаётся unavailable: поиск имён
в Downloads/репозитории не нашёл исходник. Отсутствующий источник не подменён пересказом.
Регистрация всех четырёх файлов из полного комплекта остаётся незавершённой только
в части M0; техническая подготовка M6-A от неё не зависит. CURRENT не менялся.

## Проверки и ограничения

Проверяются SHA-256 всех 18 оригиналов и трёх derived текстов, точное отличие списка
unavailable (только M0), локальные ссылки изменённых документов, git diff --check
и whitespace новых авторских документов. Производный нормативный текст не считается
авторским переписыванием; его идентичность фиксируется отдельным hash.
Фактический результат: PASS, exit 0 — 18 оригинальных hashes, 3 derived hashes,
только M0 в unavailable, 51 локальная ссылка, whitespace новых авторских документов.
`git diff --check` — PASS, exit 0. Untracked файлы проверены напрямую скриптом.
Содержательное review: границы M6-A/IA/C-54 раздельны, checksum алгоритмы названы,
исторические результаты не выданы за текущие проверки, схема и API отмечены проектом.

Backend/HTTP/DB/LLM/GC — NOT_RUN: изменения документальные, runtime/schema не менялись.
CI — NOT_RUN; перед merge обязательны frontend/pytest. Старые результаты CI/unit
