# Русскоязычная Markdown-документация базовой версии

## Результат

Нормативные документы базовой версии и шаблоны ведутся на русском языке, а
машинные идентификаторы остаются совместимыми с кодом и автоматизацией.

## Область

- Включено: отслеживаемые Git Markdown-файлы, языковое правило, проверка ссылок и команд.
- Не входит: неотслеживаемые дубликаты с суффиксом ` 2`, код, данные методологии,
  опубликованные определения агентов и изменение машинных контрактов.

## Ограничения и риски

- Перевод не должен менять нормативный смысл документов.
- Пути, команды, переменные окружения, API/JSON-поля и фиксированные значения не переводятся.
- Опубликованные версионируемые данные не изменяются на месте.

## Критерии приёмки

- [x] Языковое правило явно зафиксировано.
- [x] Нормативные baseline-документы и рабочие шаблоны переведены.
- [ ] Остальные отслеживаемые Markdown-файлы проверены и переведены там, где английский является языком прозы.
- [ ] Команды, ссылки и машинные идентификаторы сохранены.
- [ ] Обязательные проверки репозитория прошли.

## План проверки

- Проверить diff и пробельные ошибки.
- Проверить относительные Markdown-ссылки.
- Выполнить обязательные команды из `AGENTS.md`.

## Откат

Отменить отдельный документационный коммит. Изменений схемы, конфигурации и данных нет.
