# Устранение уязвимостей frontend-инструментов

## Результат

Воспроизводимая установка из `package-lock.json` не содержит известных npm-
уязвимостей, а CI блокирует новые уязвимости уровней high и critical.

## Область и ограничения

- Обновляются только зависимости инструментов разработки без major-переходов.
- Runtime API, схема БД и пользовательские данные не меняются.
- Low/moderate advisory видны в логе, но не блокируют CI автоматически.

## Критерии приёмки

- [x] `npm ci` воспроизводит установку из lockfile.
- [x] `npm audit --audit-level=low` сообщает 0 уязвимостей.
- [x] Lint, frontend build и стандартные backend-тесты проходят.
- [x] Frontend CI выполняет `npm audit --audit-level=high`.

## Откат

Вернуть изменения `package-lock.json` и CI workflow. Изменений БД и отдельных
операций отката на сервере нет.
