# Целостность Red Flags методологии 1.1

## Результат

Сборщик M2 сохраняет 18 нормативных Red Flags K2 без разбиения номера кода,
а форматы источников и контрольные количества находятся в версионированных
JSON-артефактах, а не в Python.

## Область

- Включено: стратегии разбора Red Flags, внешний import profile, нормативный
контроль, семантическая валидация, Schema, manifest и регрессионные тесты.
- Включено: доказательство сохранения содержания при преобразовании — обратная
  сборка каждой исходной ячейки Red Flags, дословное сравнение после нормализации
  пробелов и аудируемый `transformation-report.json` с парой checksum по Indicator.
- Не входит: публикация методологии 1.1, изменение default configuration,
  заполнение связей Case–Indicator и пересчёт результатов оценивания.

## Контекст

- Дефект: шаблон нумерованного списка делил суффикс `-01.` явного RF-кода.
- Повреждённый пакет содержал 54 записи K2 вместо 18, включая 36 обрывков.
- Методология 1.1 не импортирована в БД, поэтому миграция данных не требуется.

## Ограничения и риски

- `import-profile.json` является явным решением о формате каждой группы
  источников; смешанный формат K3 описан overrides конкретных Indicators.
- `normative-control.json` является контрольным артефактом, но не заменяет
  методическую ревизию текстов.
- Изменение управляющих файлов меняет checksum manifest.

## Критерии приёмки

- [x] K2 содержит 18 Red Flags и ни одного числового или кодового обрывка.
- [x] Общий состав: K1=0, K2=18, K3=27, K4=5.
- [x] Код каждого Red Flag принадлежит своему Indicator и уникален.
- [x] Форматы, уровни, runtime binding и количества отсутствуют в Python-константах.
- [x] Manifest покрывает import profile, normative control и JSON Schema.
- [x] Для каждого из 61 Indicators checksum нормализованного источника совпадает
  с checksum обратной сборки результата; отчёт имеет статус `PASS`.

## Проверка

- Unit: явный код, нумерованный список, одиночный текст и отклонение обрывков.
- Регрессия: искусственно повреждённый результат структурно похожего разбиения
  отклоняется проверкой сохранения содержания независимо от контрольных количеств.
- Полная пересборка из восьми исходных документов M2.
- Стандартные проверки репозитория.
