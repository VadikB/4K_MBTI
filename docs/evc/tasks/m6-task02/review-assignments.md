Дата решения: 2026-10-02.
Основание: сообщение пользователя в текущем рабочем диалоге.
Контактные адреса не сохраняются в Git и не входят в QA-материалы.

| Идентификатор | Роль | Область |
| --- | --- | --- |
| `methodologist-01` | Методолог | M6 v1.8, границы Fragment/BS/Evidence/EB, атрибуция по полному M2, различение технической ошибки, отсутствия возможности/материала и доказанного невыполнения |
| `expert-k1-k4-01` | Эксперт по компетенциям | K1.I13 v1.1 и K4.I05 v1.0, полные Function/Product/L0–L3/Boundaries/EP, фактические проявления в каждом Dialogue |

Оба участника рассматривают один и тот же [слепой пакет](../../../../tests/fixtures/m6_gc/v1/blind_review/manifest.json)
независимо. До фиксации первичного заключения им не показывается `draft_analysis` Codex и заключение другой
стороны. После двух первичных заключений открываются проекты цепочек и выполняется
согласование расхождений. Дата, фактический состав просмотренных файлов и решение
подтверждаются самими участниками в возвращённых карточках.

Тексты передачи: [методологу](methodologist-request.md) и
[эксперту K1/K4](expert-k1-k4-request.md). Статус: подготовлены; отправка и получение
заключений не выполнялись в текущем задании. Владелец 02.10.2026 решил завершить
техническую область без ожидания экспертизы.

## Задание `methodologist-01`

Для каждого файла из `tests/fixtures/m6_gc/v1/blind_review/` рассмотреть
`as_snapshot`, `material`, `review_scope`, `semantic_expectations` и полные criteria.

Вернуть по K1.I13 и K4.I05:

1. возникла ли фактическая возможность проявления;
2. точные пользовательские Turns и минимальные смыслосохраняющие Fragments;
3. наблюдаемые BS и их форма: действие, объяснение, план, прошлое или цитата;
4. Simple/Composite либо отсутствие Evidence, с единым основанием Composite;
5. допустимые context refs на момент проявления;
6. существенные ограничения и противоречия;
7. предметные замечания к самому кандидату или норме отдельно от ошибок механизма.

IA/L0–L3, IE, Score и C-54 в этой части не утверждать: текущая область — M6-A.

## Задание `expert-k1-k4-01`

Независимо выполнить ту же процедуру с фокусом на точном соответствии:

- K1.I13: реконструкция фактически выраженного смысла и позиции; отделить от
  организации слушания, проверки понимания и оценки истинности сообщения;
- K4.I05: субъект поставил два или более конкретных сведения в отношение;
  отделить различие знаменателей/определений от достоверности одного сведения,
  поиска отсутствующих данных и общей рамки проблемы.

Для каждой предложенной связи привести Function → Product → EP → Boundary и точные
адреса в материале. Решение о полном/ограниченном запуске само по себе не является
доказательством уровня или качества Indicator.

## Форма возврата одного независимого заключения

```text
Reviewer ID:
Role:
Candidate ID / version / material_sha256:
Reviewed files and versions:
Prior access to draft_analysis: NO / YES + details

IndicatorID / M2 version:
Opportunity: YES / NO / UNRESOLVED
Fragments: TurnID, [start,end), exact quote
BS: description, form, context refs available at that Turn
Evidence: Simple / Composite / NONE
Evidence basis and role of each BS:
Function / Product / EP / Boundary reasoning:
Limitations and contradictions:
Open methodological questions:

Independent conclusion status: COMPLETE / OPEN
Date and confirmation by reviewer:
```

Заключение со статусом OPEN не отклоняется и не превращается в IE пользователя.
После получения обоих файлов архитектор формирует таблицу расхождений; решение
об утверждении GC принимает соответствующий человек-владелец, не Codex.
