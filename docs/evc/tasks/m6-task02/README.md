## Предметная точность

CASE-TDISC-01 **v0.1 WORKING**, BaseRole `project_product_process_manager`.
Путь каталога `1.1` не меняет версию Case. В AS оставлены все 9 исходных целей.
Фокус — K4.I05 и K1.I13; остальные семь явно `UNREVIEWED_TARGET`.
Их пустые контейнеры нужны только для формы M6-A и не означают доказанного отсутствия Evidence.
Модель при реальном запуске получает все девять целей; приёмка всего её ответа требует
расширения предметной экспертизы. K3 не добавляется в Case01; отдельный кандидат на Case03
здесь не заявлен и не засчитывается в покрытие K3.

K4.I05: `Матрица K4!E10:N10`, K1.I13: `Матрица K1!E18:N18`.
G/H — функция/продукт, I:L — полные уровни, M — границы, N — EP.
Проекты не присваивают уровни по кратким названиям или по решению «перенести/запустить».
D1 содержит три разных знаменателя; D3 раскрывается после первой содержательной реакции;
D2 не раскрыт ни в одном кандидате. Час до рекомендации спонсору — условие Case,
не бюджет Cycle. Доступность данных определяется последовательностью событий, а не
их наличием в закрытой карточке или в более позднем финальном входе.
