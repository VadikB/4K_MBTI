# Обращение к эксперту K1/K4

**Тема:** M6-A — независимое заключение по K1.I13 и K4.I05

Вы назначены экспертом по компетенциям K1/K4 для независимого рассмотрения
кандидатов M6-A. Область — Fragment → BS → Evidence → EB. Не требуется назначать
L0–L3, IE, Score, C-54 или принимать механизм к выпуску.

Материалы:

- слепой пакет: `tests/fixtures/m6_gc/v1/blind_review/`;
- manifest пакета: `tests/fixtures/m6_gc/v1/blind_review/manifest.json`;
- назначение и форма ответа: `docs/evc/tasks/m6-task02/review-assignments.md`;
- исходники и хеши M2: `tests/fixtures/m6_gc/v1/manifest.json`.

До фиксации первичного заключения просьба не открывать проект анализа Codex и не
обсуждать выводы с методологом.

Для каждого из 11 Candidate ID рассмотрите полные критерии из frozen input:

- **K1.I13 v1.1:** реконструкция фактически выраженного существенного смысла и
  позиции другого. Отделите её от процесса слушания K1.I12, проверки понимания
  K1.I14, общей карты ситуации K1.I01 и оценки истинности по K4.
- **K4.I05 v1.0:** пользователь поставил два или более конкретных сведения в
  отношение согласования, дополнения, противоречия или несопоставимости.
  Отделите это от достоверности одного сведения K4.I03, поиска отсутствующих
  данных K4.I06 и построения общей рамки K4.I08.

По каждой предлагаемой связи приведите точные TurnID/[start,end)/quote,
наблюдаемую операцию, Function → Product → EP → Boundary, форму проявления,
доступные на тот момент context refs и ограничения. Решение о полном или
ограниченном запуске само по себе не доказывает качество Indicator.

Верните одно заключение на кандидата по форме из `review-assignments.md`.
Зафиксируйте просмотренные версии/хеши, предшествующий доступ к draft, статус
COMPLETE или OPEN, дату и подтверждение автора. OPEN не является IE пользователя.

После получения заключения его сопоставят с независимым мнением методолога.
Проект Codex откроется только после фиксации обеих первичных версий.
