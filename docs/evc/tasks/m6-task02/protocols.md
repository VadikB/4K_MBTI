# Два отдельных протокола

## Независимое утверждение (шаблон, не заполненный акт)

| Поле | Значение |
| --- | --- |
| Candidate ID / версия / SHA входа | Заполнить из manifest и material_revision |
| AS / Dialogue / IndicatorIDs / версии M2 | Заполнить из входа |
| Методолог: идентификатор, полномочия, дата, подписанное заключение | `methodologist-01` назначен пользователем 02.10.2026; заключение не получено |
| Эксперт по компетенции: идентификатор, полномочия, дата, подписанное заключение | `expert-k1-k4-01` назначен пользователем 02.10.2026 для K1/K4; заключение не получено |
| Порядок доступа к исходникам и проекту Codex | Заполнить фактическую историю |
| Первое независимое заключение | Не получено |
| Второе независимое заключение | Не получено |
| Смысловые основания, допустимые эквиваленты, запреты | Заполняет каждая сторона отдельно |
| Расхождения / ссылки на Turns и M2 / способ разрешения | Не рассмотрено |
| Неразрешённые вопросы | Кандидат остаётся открытым |
| Решение, владелец и дата утверждения / версия эталона | Не утверждён |
| Назначение development / независимая проверка и история использования | Все текущие случаи development |

M6.9.4: два независимых заключения, затем согласование. Codex не подменяет обе стороны.
Изменение нормы/наблюдаемости направляется методологу; нарушение кода — техническому
владельцу. Неразрешённое разногласие не является IE пользователя.
Контактные данные участников находятся вне Git; задания и псевдонимизированное
назначение — в [review-assignments.md](review-assignments.md).

## Фактический прогон (шаблон, отдельно от утверждения)

| Поле | Значение |
| --- | --- |
| Run ID / время / среда / commit и локальный diff | Заполнить при выполнении |
| Утверждённый GC / версия / hash / AS × IndicatorID | Пока нет утверждённых GC |
| Полный вход, механизм, prompt, schema, provider/model/version/config | Сохранить точные значения/снимки |
| Attempt ID / ordinal / retry reason | Сохранять каждую попытку |
| Raw response / trace / error / saved revision | Защищённые ссылки; синтетический QA |
| Структурная проверка | Фактический PASS/FAIL с деталями |
| Смысловое сравнение и независимый проверяющий | Не заменять точным сравнением строк или единственным AI-арбитром |
| Нормативные ошибки M6.9.6 | Перечень, включая пропущенные/ошибочные попытки |
| Итог | PASS / FAIL / NOT_RUN с причиной |

По M6.9.5 каждый обязательный утверждённый GC выполняется успешно три раза при
одинаковом входе и версии механизма; показываются **все** попытки, ошибки и пропуски.
Не выбирать три удачных из неудачной серии. Повторы не увеличивают число случаев.
Отдельно считать: GC, AS × IndicatorID, проверки, попытки, результаты сравнения.
Сейчас: 11 кандидатов; 0 утверждённых GC; 0 реальных прогонов; 0 заключений экспертов.
PASS ограниченного набора не устанавливает популяционную точность, Reliability
или достижимость полного покрытия за 60 минут.
