# Обращение к методологу

**Тема:** M6-A — независимое заключение по кандидатам Evidence/EB

Вы назначены методологом для независимого рассмотрения кандидатов M6-A.
Область заключения ограничена цепочкой Fragment → BS → Evidence → EB по M6 v1.8.
Indicator Assessment, L0–L3, IE, Score, C-54 и выпуск механизма в эту работу не входят.

Материалы:

- слепой пакет: `tests/fixtures/m6_gc/v1/blind_review/`;
- manifest пакета: `tests/fixtures/m6_gc/v1/blind_review/manifest.json`;
- назначение и форма ответа: `docs/evc/tasks/m6-task02/review-assignments.md`;
- исходники M6/M2 и их хеши: `tests/fixtures/m6_gc/v1/manifest.json`.

В слепом пакете нет проекта анализа Codex и заключения эксперта. Просьба до фиксации
первичного заключения не открывать файлы `candidates/*/draft_analysis` и не обсуждать
выводы с другим участником проверки.

Для каждого из 11 Candidate ID и каждого IndicatorID в `review_scope` определите:

1. возникла ли фактическая возможность проявления;
2. точные пользовательские Turns и минимальные Fragments;
3. BS и форму проявления;
4. Simple/Composite Evidence либо отсутствие Evidence;
5. допустимые context refs на момент проявления;
6. связь с полными Function, Product, EP и Boundaries M2;
7. ограничения, противоречия и открытые методологические вопросы.

Особенно важно независимо различить:

- слова пользователя и персонажа;
- самостоятельно названные данные и информацию, раскрытую позже;
- отсутствие возможности, недостаток материала, доказанное невыполнение и
  техническую потерю;
- раннее слабое/ошибочное проявление и позднее исправление;
- реальный Composite и механическое объединение нескольких Turns.

Верните одно заключение на кандидата по форме из `review-assignments.md`.
Укажите фактически просмотренные версии/хеши, доступ к draft до заключения,
статус COMPLETE или OPEN, дату и подтверждение автора. OPEN допустим и не означает IE.

После получения двух независимых заключений будет подготовлена таблица расхождений.
Проект Codex откроется только на этапе согласования.
