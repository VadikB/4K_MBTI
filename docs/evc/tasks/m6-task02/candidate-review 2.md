# Пакет независимого рассмотрения

Сначала эксперт получает исходные `as_snapshot` и `material` каждого JSON,
полные M2 и исходный Case. `draft_analysis` Codex открывается после фиксации
первичного независимого заключения. Оно не является подсказанным эталоном.
Если эксперт прочитал проект заранее, это отражается в журнале доступа.

Общий источник Case: `Паспорта`, строки 2–23; `Участники`, строки 2–5;
`Индикаторы`, строки 2–10; `Данные`, строки 2–4; `Сценарий`, строки 2–5
исходного XLSX из manifest. Матрицы M2 — точные ячейки в `sources/m2-cells.json`.

| JSON в candidates | Что сопоставить и решить независимо |
| --- | --- |
| independent | Самостоятельное сравнение D1 по объектам/знаменателям → K4.I05; реконструкция фактически высказанных позиций → K1.I13. Проверить границы с I14 и K4, не оценивать истинность позиций как понимание. |
| character | Слова сравнения дословно совпадают с independent, но принадлежат Илье. У пользователя прекращение обсуждения без сравнения. Не превращать контекст персонажа в пользовательский BS. |
| before_disclosure | Пользователь произносит числа до события D1. Материал сохраняется, происхождение чисел не установлено. Наличие D1 позже не обосновывает доступность задним числом. Решить допустимость/ограничение атрибуции. |
| composite | Сначала пользователь приписывает Вере невозможность любого запуска, затем исправляет реконструкцию. Решить, нужен ли единый Composite по K1.I13; роль каждого BS и раннее искажение сохраняются. Само количество Turns не критерий. |
| no_opportunity | Capture остановлен до предъявления позиций/данных, пользовательских Turns нет. AS подготовлена, но её вводная ещё не предъявлена. Не подменять плановую возможность фактической. Пустая цепочка, без фиктивного BS. |
| insufficient | D1/D3 доступны, ответ «не могу сформулировать» не даёт сравнения/реконструкции. Различить нехватку материала и доказанное невыполнение по полному Dialogue. |
| nonperformance | Прямая реплика об отказе сравнивать доступные данные. В проекте пустая цепочка: эксперт должен проверить, достаточно ли условия и отказа для основания доказанного невыполнения; IA сейчас не назначать. Отказ сам по себе не универсальный L0. |
| contradiction | Среднее 90%, 60%, 30% ошибочно названо готовностью, затем сравнение исправлено. Оба проявления в Composite; поздний текст не удаляет ранний. Проверить единство объекта и роль новых условий. |
| paraphrase | Сопоставить с independent по смысловым основаниям, а не совпадению строки/границ. Автор и доступность сохранены. Эквивалентность пока проектная. |
| retain | После D3 рекомендация о переносе сохраняется с основанием о непроверенном импорте. Сохранение позиции не ошибка автоматически; изменение не улучшение автоматически. |
| technical_loss | После предъявления данных зафиксирована ошибка передачи, ответа нет. Нельзя выводить, что пользователь ничего не сделал. Ошибка не порождает IA/IE/L0 и не является экспертным расхождением. |

Для каждой строки заполняются две независимые карточки по шаблону протокола.
Указать точные TurnID/Fragment, существенные оговорки, доступные сведения,
операцию → функцию/продукт/EP/границу M2, пустоты и ограничения.
В JSON каждый Fragment использует Unicode offsets `[start,end)`; некоторые проекты
берут полный короткий Turn для сохранения оговорок. Эксперт может обоснованно сузить
границу без требования побуквенного совпадения с проектом.

Все случаи — development, подготовлены и просмотрены Codex. Независимый held-out
набор ещё не сформирован. После утверждения выделить новые/не использованные при
настройке случаи и журналировать доступ; не переименовывать уже использованный набор
в независимый. Количество 11 объясняется контрастами, не квотой GC.

Неясность и разногласие экспертов хранятся в карточках как открытые вопросы кандидата.
Они не превращаются в IE пользователя. Утверждённый эталон меняется только новой
версией с предметным основанием, исходные заключения сохраняются.
