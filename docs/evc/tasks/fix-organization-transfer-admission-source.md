# FIX-ORG-TRANSFER-01: восстановить перенос участника между организациями

## Результат

Перенос участника суперадминистратором сохраняет происхождение связи
`superadmin_transfer` и не завершается ошибкой PostgreSQL `CHECK`.

## Область

- Включено: идемпотентное обновление ограничения
  `organization_memberships_admission_source_check`; регрессия миграции и переноса.
- Не входит: изменение API, UI, ролей, назначения оценки и данных участников.

## Контекст

- Основание: воспроизведённая владельцем и агентом ошибка на test-контуре 2026-11-03.
- Значимые точки входа: `Api/database.py`, `Api/routes.py`,
  `tests/integration/test_arch30_transfer_db.py`.
- Архитектурный адрес: инфраструктурная схема организации; владелец данных — backend.
- Прослеживаемость: действие «Перенести» → `transfer_admin_organization_user` →
  `admission_source='superadmin_transfer'` → ограничение таблицы → integration-регрессия.
