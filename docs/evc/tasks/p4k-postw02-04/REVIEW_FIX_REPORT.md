## Где находились дефекты

| Место | Причина и исправление |
| --- | --- |
| Общий renderer | Предупреждения склеивались, название этапа повторялось, длительность росла при недоступных сведениях. Теперь отдельные факты: этап, failed, результат чтения, актуальность и задержка. При неизвестной актуальности длительность зафиксирована на успешном чтении с явной подписью. |
| Onboarding UI | `storeOperation` отбрасывал безопасную `preparation`; ошибка чтения меняла вступление и смешивалась с готовностью. Проекция сохраняется, ошибка чтения показана в своём блоке, успешное чтение её снимает, поздний снимок не заменяет более новый. Действия расположены перед раскрытием. |
| Следующая ситуация UI | Общий обработчик runtime error добавлял утверждение о неподтверждённом черновике даже после завершённой ситуации. Теперь сбой чтения отражён в подготовке, подтверждённая сохранность ответа не меняется. Убраны повторы под кнопкой и название состояния «Сейчас пауза». |
| Время и mobile header UI | `is-paused` выставлялся при любом `between_situations`; теперь требуется серверное `blocking_system_wait`. Серверный расчёт времени сохранён. Неизвестен остаток — подписано, что уточняется остаток времени выполнения. Бренд не скрыт на mobile; разрешённые кнопки переносятся на 320 px. |
| Подготовка отчёта UI | Вступление заменено одним абзацем, убран дублирующий общий статус. «Мои оценки» ведёт в прежний кабинет; проверка использует прежние GET. Failed заменяет спиннер ошибкой; готовый ограниченный отчёт остаётся готовым. |
| Admin UI | Подробности были внутри узкой колонки, строки центрировались по высоте. Теперь compact summary и full-width disclosure под строкой. Перенос узлов сохраняет раскрытие; статусное уведомление проверки не отбирает фокус. Историческое наблюдение не перекрывает отмену назначения или блокировку старта. |
| Admin fixture | Стадия была добавлена участнику с `assessment_assignments: []`. Исправлены связанные назначение, программа и подтверждённая редакция анкеты; регистрация задана отдельным согласованным фактом. Отдельные участники показывают отсутствие назначения/чужую программу и отмену назначения. Проверка анкеты в production не удалялась. |
| Production projection | Код API не изменён. Просмотрены предикаты точного user/org/assignment/profile/questionnaire в `routes._build_admin_organizations`, привязка next к Cycle/user, выбор новейшего поколения и отсутствие догадки в flat compatibility. Реальные функции проекции/маршрута проверены адресно. Причина серверного сбоя по снимкам не устанавливалась. |

## Состояние → текст → действия

| Состояние | Основной текст | Доступные действия |
| --- | --- | --- |
| Свежий выполняющийся этап | Одно фактическое название и короткое пояснение | Проверить состояние, прежний переход в «Мои оценки», раскрытие |
| Свежий длительный этап | «Подготовка занимает больше времени»; название не повторяется | Те же действия; задержка не даёт автоматический retry |
| Сведения устарели | «Последний известный этап: …»; «Сведения могут быть устаревшими. Проверьте состояние» | Read-only проверка и раскрытие; длительность на момент обновления |
| Сбой чтения | «Не удалось обновить состояние. Показаны последние полученные сведения» | Read-only проверка и раскрытие; подтверждение ответа сохранено |
| Чтение успешно, исполнитель не подтверждён | «Сейчас не можем подтвердить, что подготовка продолжается» | Проверка и раскрытие; без утверждения о соединении пользователя |
| Подтверждённый failed | «Не удалось завершить подготовку оценки/следующей ситуации/отчёта» и безопасный этап | Проверка; повтор подготовки только при прежнем серверном retry_allowed; без активного спиннера отчёта |
| Failed и новое чтение не удалось | Ошибка подготовки и ошибка чтения — отдельные абзацы | Те же разрешённые действия; failed не теряется |
| Отчёт готов с ограничениями | «Ваш результат готов» и прежнее объяснение ограничений | Посмотреть результат, «Мои оценки»; ожидание не возобновляется |
| Отменённое/отсутствующее назначение | «Назначение отменено» / «Оценка не назначена» | Прежние разрешённые действия; чужое/историческое наблюдение не изображает текущую подготовку |

В свёрнутом виде номер и даты не выводятся. В сведениях: вид, этап, начало,
последнее изменение, «Сведения обновлены», полный «Номер подготовки» с объяснением
и копирование. Номер прежний стабильный, не случайный. Копирование содержит понятное
описание и полный номер; отказ буфера не даёт ложного успеха. Обновления не раскрывают
блок и сохраняют сознательное раскрытие/фокус той же операции.
