## Основания и границы

Применены [архитектура 1.0](../../../architecture/product-4k/1.0/context.md),
[Change 01](../../../architecture/product-4k/1.0/updates/2026-10-01/README.md),
[Registry](../../../architecture/product-4k/registry.md) и
[SourceSet](../../../methodology/source-sets/2026-10-01/manifest.json).
PM-03 и C-34 определяют допущенную AS. PM-04, LU-04.3–04.5 исполняют сценарий,
фиксируют Turn и уточнение. M5 v1.1, M6 v1.8 и M7 v1.3 применяются в границах
этой задачи. Редакцию глоссария 30.09 сверили по
[локальным разделам Dialogue и Turn](../p4k-postw02-04/evidence/glossary-sections.txt).

Публичная проекция показывает формат из сохранённого состава активных
персонажей AS. В функциональном пакете CASE.SPEC.02 этот состав пуст,
в CASE.SPEC.01 есть активный персонаж. Проверка проходит до первой реплики.
Для старого снимка без достоверного состава действует нейтральная подпись.
Действующий ASK меняет формат интерфейса на «Уточнение».

При сетевой неопределённости используется чтение исходных `request_id`
и `turn_id`. 409 может прийти после записи Turn. Ошибка с доступным повтором
появляется после проверки отсутствия точной записи и обновления разрешений
от runtime. Принятый Turn со сбоем проверяется чтением статуса. Код
использует подтверждённый интервал M7 для утверждения об остановке времени.
Подвал использует общий компонент, текущие ссылки и номер версии.

## Проверка и откат

Раздел «Проверка» PR содержит результаты шести критериев, точный SHA,
подборку и ссылки на проверки. Используются Chromium, управляемый HTTP
и отдельный синтетический PostgreSQL. Размер видимой области под клавиатуру
воспроизводится через событие изменения `visualViewport`.

Изменение расширяет публичное чтение runtime совместимыми полями. Откат
через revert и пересборку frontend. Старые снимки AS, черновики, сохранённые
Turns и переход ASUX‑04 сохраняют прежнюю схему.
