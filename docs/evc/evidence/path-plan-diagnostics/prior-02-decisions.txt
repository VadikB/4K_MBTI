Каждая карточка содержит входы, результат, границы, тесты, неизменяемые версии, риски и откат. Один PR — один независимо принимаемый результат по текущим правилам репозитория. Не наследовать автоматически правило «один общий merge всего F-блока» на новую серию. Размеры PR, зависимости и кандидата версии согласует архитектор в рамках действующего процесса. Полный обязательный CI и human review требуются перед каждым слиянием; выпуски не получают повторную версию на каждый рабочий коммит. Публикация методологических пакетов/пилот на людях — отдельное основание.
