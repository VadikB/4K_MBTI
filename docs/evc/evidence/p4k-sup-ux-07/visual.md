# P4K-SUP-UX-07 · Визуальная сверка

Проверка от 23.11.2026. Продукт 2.1.71, база `ec9766e7` и локальный diff 07.
Chromium из Playwright 1.63.0. Эталон карточки взят из приложения `reference.zip`,
страница `/v1.6/?screen=problem&issue=report&view=screen`.
Идентификаторы, результаты, организации и имена синтетические.
Снимки продукта фиксируют выполняемый интерфейс с детерминированными HTTP-ответами.
Серверные права и сохранённые редакции проверены отдельно на PostgreSQL.

Порядок в карточке совпадает с эталоном: заголовок и статус, подготовка передачи и
чтение, наблюдаемый факт, данные поиска, доступность действий, ход операции. Onest и
цвет заголовка `rgb(34, 44, 48)` совпадают. Сетка переходит с двух колонок на одну.
Ширина документа равна viewport на всех трёх размерах. В продукте проверены фокус
повторного чтения с клавиатуры и возвращение фокуса после ошибки PDF. В карточке
обычного оператора есть чтение и подготовка передачи. Скачивание при действующем
доступе повторяет тот же запрос по `report_id`. После серверного отказа кнопка отключается.

Отличия от v1.6: штатная шапка и подвал продукта, номер организации, отображение
реальных серверных метаданных Cycle, Results и Report, нейтральный блок доступности
действий по текущей роли и фактические временные отметки вместо событий прототипа.
Для PDF кнопка меняет подпись на «Повторить скачивание PDF», отчёт остаётся открыт.

Два отдельных эталона отчётов возвращают HTTP 401 и отсутствуют в приложенном архиве.
Во встроенном браузере показана форма входа. Автопроверка отклонила переход по кнопке
«Продолжить через ChatGPT», поскольку он инициирует передачу данных учётной сессии
внешнему сайту. Сравнение этих двух пар имеет статус NOT_RUN. Для завершения сверки
подойдёт локальная копия соответствующей редакции или явный допуск к входу на сайт.
