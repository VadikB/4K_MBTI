Playwright подтвердил Onest, цвет заголовка `#222c30`, две колонки на 1440 px
и одну на 390/320 px, отсутствие горизонтального переполнения, клавиатурное
повторное чтение с восстановлением фокуса, копирование и возврат к карточке.
У администратора команды повторной отправки и отзыва видимы в меню действующей
ссылки. Проверены границы меню, открытие по Enter и закрытие по Escape.

В продукте используется общий безопасный номер INV, отдельный от кода HTTP.
Кнопка называется «Проверить отправку». Факт почтового сервиса и состояние
ссылки показаны раздельно. Номер организации цифровой. Индикатор неизвестного
исхода использует нейтральный стиль кабинета UX‑05. В пакет не входят заметки,
отметка о передаче или ручная ссылка в рабочий канал.

Внешний эталон меню администратора вернул HTTP 401. Для него приложены
снимки продукта, парное сравнение ожидает доступ к странице.
