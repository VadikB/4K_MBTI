# Task SourceSet для Change 01

[Manifest](manifest.json) фиксирует 18 доступных оригиналов: путь от корня репозитория,
SHA-256, выбранную версию/статус. Уже сохранённый M1 используется по существующему
пути без повторного импорта. Это архив источников задачи, не runtime package,
не центральный Registry и не публикация CURRENT по M0.

Комплект выбран в Change 01, включение согласовано пользователем. Проверка
идентичности файлов не равна повторному утверждению методологии или полному аудиту
их взаимной согласованности. Не нужно перечитывать все 15 файлов для каждой задачи.
Маршрут чтения — в [поправке](../../../architecture/product-4k/1.0/updates/2026-10-01/README.md).

Дополнение от 02.10.2026: M6 v1.8, M7 v1.3 и M8 v1.2 зарегистрированы
побайтово в originals; тексты абзацев/таблиц — в derived. Их hashes записаны
в manifest отдельно. Графические схемы в производных текстах не воспроизводятся;
при расхождении сверять DOCX. Регистрация не является runtime publication.
В unavailable остаётся только M0 v1.0: оригинал не найден по именам в Downloads
и репозитории. Хеш из постановки не заменяет исходный файл.

M8 REVIEW внутри старого M1 остаётся исторической ссылкой; для данной задачи
выбран M8 v1.2 FROZEN по Change 01. M1 CURRENT=NO сохраняется.

Оригиналы скопированы побайтово до «СТОП», повторно не создаются. Новая редакция
источника требует отдельного изменения SourceSet с явной областью влияния.
Пути и SHA-256 каждой записи сверяются перед зависимым изменением, факт чтения
отмечается отдельно в задаче. Исторический Google Docs не является входом этого набора.
