# Технический контракт M7 Cycle Planning v1

Дата: 02.10.2026. Статус: draft QA. Источник: M7 v1.3 §§1–5, 6.2,
6.5–6.6, 7–9; M1 v1.4; Change 01 И-2/4/6; ADR-002.

## Владение и границы

План Cycle и маршрут принадлежат PM-04. PM-03 остаётся владельцем подготовки и
допуска AS; PM-05 предоставляет факты C-54. Планировщик не формирует вопросы M7,
не вычисляет M6 Scores/допустимые вклады и не закрывает Cycle вместо state machine.

Один Cycle имеет один логический план и append-only revisions. Профиль, полный и
плановый состав, требования наблюдений и два лимита времени фиксируются до старта.
Цели берутся из выбранного состава M2, а не из первого Case. Старый
`create_cycle_session_for_case` остаётся ограниченным QA helper.

## План и алгоритм

Draft artifact `m7_cycle_plan/1.0.0` хранит defaults 60 минут/72 часа,
`m7-greedy-coverage/1`, источник длительности и tie-break. Сначала применяются
обязательные ограничения статуса Case, роли, QA и вклада; затем выбирается максимальный
вклад в ещё не обеспеченные Indicators, ширина Skills, меньшая верхняя длительность,
CaseID и версия. Case остаётся условной возможностью, а не фактическим покрытием.

Текущий WORKING-пакет не образует допустимый маршрут и корректно возвращает `NO_ROUTE`.
Синтетическая FROZEN fixture применяется только в integration QA.

## Решение следующей AS

Решение сверяет plan revision, Cycle/Session, незакрытую AS, время, последние C-54,
уже использованные Cases и остаток требований. Результаты: `SELECTED`,
`WAITING_CURRENT_AS`, `NO_ADMISSIBLE_CASE`, `OUT_OF_TIME`, `COLLECTION_CLOSED`.
L0–L3 считаются итоговым IA; низкий уровень не создаёт повтор. IE, отсутствие
возможности, pending и technical failure остаются разными причинами.

Для `SELECTED` PM-03 готовит AS существующим сервисом, а назначение сохраняется
отдельной записью. Предъявление повторно проверяет revision, состояние и admission,
запускает первую Session и AS через существующий runtime. Idempotency key привязан
к Cycle и plan revision; повтор возвращает прежнее решение.

## Данные, совместимость и откат

Новые таблицы: `m7_cycle_plans`, `m7_plan_revisions`, `m7_plan_request_keys`,
`m7_next_as_requests`, `m7_route_decisions`, `m7_route_assignments`. История плана
и решений immutable; назначение отделено от решения. Существующие Cycle/Session/AS,
target_set и прошлые данные не переписываются.

Откат запрещает новые M7 QA requests и предъявление ещё не запущенных назначений,
сохраняя планы, решения и AS для readback. Draft artifact не включается в основной
пользовательский путь и не получает статус CURRENT/FROZEN.
