# M7 Return and Time Integration v1

Дата: 15.10.2026. Статус: **draft QA integration**, production activation blocked.
Основание: UX-P03 rev 1.0, UX-P01 rev 2.0, UX-P02 rev 1.0, Change 01,
M7 v1.3 и действующие M5/M7 runtime-контракты.

## Граница первого этапа

Реализован только интеграционный адаптер для контролируемого серверного события
отсутствия в `qa` Cycle. Источник production-события D08, состояния неудачи D09,
ограничение повторов и `scenario_ended` с уточнениями не определяются этим кодом.
При отсутствии контролируемого события read model возвращает
`dependency_unavailable`; скрытого определения отсутствия по login, refresh,
visibility или молчанию нет.

Политика `ux-p03-controlled-return/1.0` хранится как immutable draft artifact.
Граница 180 секунд применяется к сохранённому `recognized_at`: 179 продолжает
текущую AS, 180 требует готовый допущенный candidate P02 и атомарное переключение P01.

## Чтение и команда

Read-only state возвращает owned Cycle, устойчивую позицию/current AS, признанную
длительность, допустимое действие, маршрутный прогресс, остаток бюджета и deadline.
GET не создаёт AS и не потребляет idempotency key.

Явная команда Continue принимает expected position/AS/state и key. Она повторно
проверяет Cycle, AS и оба лимита. Короткая ветка сохраняет AS. Длинная ветка принимает
только уже сохранённую и допущенную operation P02, вызывает P01, предъявляет новую AS
и затем сохраняет replayable result. Старые Turns не копируются.

Контролируемое событие открывает `blocking_system_wait`; Turn во время открытого
ожидания запрещён. После успешной команды ожидание закрывается и `collecting`
возобновляется. Уже использованный бюджет не возвращается, deadline не меняется.

## Совместимость и откат

Схема аддитивна. Product event ingestion и production provider отсутствуют, поэтому
наличие кода не включает механику для assessment. Откат запрещает новые P03-команды,
но сохраняет события, операции P01/P02 и route history; автоматически возвращать
заменённую AS в расчёт нельзя.
