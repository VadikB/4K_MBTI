## Область применения

Источник обязателен для анализа и проектирования изменений понятийного контракта.
Он не задаёт физическую схему БД/API и сам по себе не разрешает изменять опубликованные
пакеты, исторические снимки, контракт оценивания или состав исполняемой методологии.
До публикации по M0 не назначать его CURRENT. При конфликте с применяемым комплектом
фиксировать влияние и получить предметное решение до зависимой реализации.
Существующее поведение не объявлять соответствующим M1 лишь из-за наличия документа.

M1 сообщает о M5 v1.1, M6 v1.8, M7 v1.3 FROZEN и M8 v1.2 REVIEW; сами эти источники
в этой задаче не предоставлены и независимо не сверялись. Документное QA PASS,
закрытие M1-14-01–04 и решение о FROZEN — утверждения источника, не выполненные
агентом продуктные проверки. Продуктные, GC и пилотные прогоны остаются NOT_RUN.
CHECK M4 по использованию PersonalizedProfile в Recommendations остаётся OPEN.
Задачи реализации M6–M8 не считаются поставленными этим импортом.
