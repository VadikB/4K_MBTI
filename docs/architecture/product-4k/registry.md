# Реестр архитектурных источников Product 4K

Дата: 2026-09-29. Этот реестр фиксирует применимость известных источников;
полнота нормативного комплекта M0–M8 пока не подтверждена.

| Источник | Версия / статус | Применимость |
| --- | --- | --- |
| [Product Architecture](https://docs.google.com/document/d/1JMS6oCpj2f1SpRq_N-TQn5OhZK09OiJr4kBMLoP7kWM/edit?tab=t.0) | 1.0; REVIEW при чтении | Командная основа целевой архитектуры по сообщению пользователя |
| [Локальный контекст](1.0/context.md) | 1.0; принятые рабочие принципы | Постоянные правила разработки; не полный FROZEN-выпуск |
| [ADR-001](../../adr/001-assessment-platform-architecture.md) | Принято для реализации | Существующий контур версий и совместимость |
| [Runtime](../assessment-runtime.md) | Редакция в Git | Снимки исполнения и публикация |
| [Пакеты assessment](../../../assessment_definitions/README.md) | Версии и статусы в manifests | Источники исполняемых пакетов; наличие draft не даёт допуска |
| [AGENTS.md](../../../AGENTS.md) | Редакция в Git | Обязательный исполнительный контракт |

Для конкретной задачи фиксируются точные версии и checksum затронутых пакетов,
а также commit применённых локальных документов. Ссылка на изменяемый Google Docs
сама по себе не является идентификатором неизменяемого выпуска.

## Открытые решения

| ID | Вопрос | Владелец решения | Ограничение |
| --- | --- | --- | --- |
| OPEN-01 | Типы Evidence: M1 v1.3 и M6 v1.4 REVIEW | Методолог | Не придумывать итоговый перечень |
| OPEN-02 | Завершение основного сценария и всей AS/Dialogue в M5–M7 | Методолог и владелец продукта | Не вводить новые основания завершения без решения |
| OPEN-03 | M8: цели, Skill Gap и содержание отчёта | Методолог и владелец продукта | Не объявлять legacy-эвристики нормами M8 |
| OPEN-04 | Применимый комплект версий Registry | Владельцы методологии и архитектуры | Не объявлять весь комплект FROZEN/CURRENT автоматически |

Назначение конкретных ответственных и реквизиты выпуска ещё предстоит внести.
Закрытие вопроса требует ссылки на решение, версии источников и анализа влияния.
