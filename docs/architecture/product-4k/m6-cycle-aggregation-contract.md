# M6 Cycle Aggregation и C-56 v1

Статус: draft QA contract, 02.10.2026. Владелец — PM-05, потребитель — PM-06.

Расчёт относится к одному закрытому Assessment Cycle и точному
`composition_checksum` из C-46. Входом служат последние принятые final-редакции IA
каждой AS. Решение допуска хранится отдельно от IA, адресует все числовые IA
Indicator и различает пригодность для интерпретации и для общего вклада.

Числовой путь детерминирован: L0–L3 соответствуют 0–3; вклад Indicator — среднее
всех допущенных final IA; ComponentScore — среднее доступных вкладов Indicators;
SkillScore — равновесное среднее доступных ComponentScore. Значения не округляются,
в C-56 сохраняются числитель и знаменатель. `INSUFFICIENT_EVIDENCE`, отсутствие IA,
техническая ошибка и недопущенный набор не становятся нулём.

Для каждого целевого Skill сохраняется один из исходов `full_score`,
`partial_score`, `result_without_score`, `no_result`. Пять независимых покрытий
содержат числитель, знаменатель, включённые/отсутствующие IDs и причины пробелов для
плана Cycle и полного состава выбранных Skills по M2.

`m6_cycle_calculations` хранит неизменяемые редакции входа, результата и C-56 с
checksum. Одинаковый idempotency key с иным запросом отклоняется. Публикация записи
и reconciliation C-46 выполняются в одной транзакции вызывающего endpoint; конфликт
состава не позволяет пометить Cycle рассчитанным. Результат адресуется PM-06 только
после закрытия collection и успешной final-обработки принятого материала.

Контур доступен superadmin для синтетической QA. Пакет правил
`m6_cycle_aggregation/1.0.0` имеет статус draft. Он не присваивает CURRENT, не
утверждает GC/Reliability и не создаёт Results, Skill Level, Gap или Report M8.
