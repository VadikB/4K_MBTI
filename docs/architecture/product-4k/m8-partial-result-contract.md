# M8 Partial Result Contract

Версия `m8-partial-result/1.1.0`, WORKING. Контракт не меняет M6 outcomes и не
присваивает методологии CURRENT.

`partial_result.progress.completed/planned` — число AS с final C-45 handoff / число
элементов frozen route принятой plan revision. `presented`, `interrupted` и
`not_presented` выводятся из lifecycle AS; число Turns в формуле не участвует.
Уменьшение текущего route не меняет сохранённый знаменатель старого Cycle.

Причины независимы: `plan_scope`, `collection_incomplete`, `observation_missing`,
`context_limited`, `technical_failure`. Отсутствие наблюдения не равно L0. Частный
Score, качественный IA без Score и `no_result` сохраняют исходные M6 значения.

## Раздельная проекция REPORT-03

`plan_completed` определяется по сохранённому C-46: число завершённых позиций
принятого маршрута относительно длины frozen `plan.untraversed_route`. Если позиций
в историческом C-46 нет, применяется число final C-45 handoff; пустой/неизвестный
план не объявляется завершённым. `is_incomplete` остаётся совместимым обратным
полем и теперь означает только `!plan_completed`. Причина закрытия, включая
`time_budget`, не подменяет фактический прогресс. Новый состав программы не
пересчитывает старый знаменатель.

| Поле | Сохранённый источник | Смысл |
| --- | --- | --- |
| `plan_scope_limited` | C-56 `cycle_plan` и `full_m2` | Принятый план охватывал часть состава M2; выполнение плана от этого не меняется. |
| `observation_limited` | C-56 покрытие фактических IA | В плане остались цели без достаточных наблюдений. |
| `source_limited` | C-56 `limitations` | Есть иное исходное ограничение; исходные строки сохраняются в Results/Report. Оно не объявляется ограничением контекста по догадке. |
| `technical_failure` | Сохранённые failed admissions M6 | Ошибка обработки отдельно от качества навыка и полноты маршрута. |

`limitation_reasons` содержит `code` для системы и `message` из точной версии
пакета отчёта. Неизвестный код не выводится человеку вместо текста: применяется
безопасная общая формулировка, исходный код остаётся в сохранённых данных.
`context_limited` зарезервирован для явно классифицированного ограничения
контекста; произвольная строка C-56 не устанавливает его автоматически.

У каждого Skill сохраняются исходный M6 `outcome` (`full_score`, `partial_score`,
`result_without_score`, `no_result`) и исходный `score`, включая 0 и `null`.
`presentation` добавляет человекочитаемую подпись и причины, исходные коды
`missing_reasons`, включённые/отсутствующие IndicatorIDs и проверку связи
невыполненной позиции frozen route с навыком. `remaining_plan_relevant` равен
`null`, если связь не подтверждена; неизвестность не означает `false`. Публичная
проекция скрывает внутренние IDs, сохраняя подписи и ограничения. Эти сведения
нужны для адресной проверки сопоставимости REPORT-07; один неполный Cycle не
запрещает автоматически сравнение уже достаточного навыка.

Новая версия содержательного пакета `m8_basic_report/1.5.0` используется
только для новых Cycle. Пакет `1.4.1` и неизменяемые Results/Reports не
перезаписываются. Чтение старого Report может исправить ошибочный заголовок
прохождения по сохранённому прогрессу без изменения его checksum.

Новая оценка создаётся только явным `POST /assessment/cycles/start`. GET/status
возвращает описание действия, но ничего не создаёт. POST повторно проверяет active
organization membership, выбранный profile/BaseRole, configuration и catalog; новый
Cycle не меняет snapshot, Results или Report прежнего Cycle.
