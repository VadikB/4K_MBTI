# Bootstrap v1 — техническая базовая схема нового стенда

`base.sql` создаёт отсутствующие до EVC таблицы. Затем выполняются неизменённые
публичные ensure-функции `Api/database.py`, auth/web session и M5 lab.
Схема не содержит пользователей, кейсов, оценок или отчётов.

Происхождение: текущие SQL-контракты `Api/agent.py` (USER_SELECT_SQL и
_save_user_profile/_load_roles), `Api/auth_service.py`, `Api/web_session_service.py`,
`Api/routes.py` (_build_dashboard), `Api/assessment_service.py` и FK/additive DDL
`Api/database.py`; существующие integration fixtures подтверждают зависимости,
но не вызываются перед bootstrap. Исторического полного DDL в Git нет.

Область: новое приложение Cycle M5–M8 и обязательные auth/dashboard зависимости.
Это не восстановленный дамп и не гарантированная схема всех исторических legacy
оценок. Зависимость dashboard от user_assessment_progress удалена по решению владельца;
используются сохранённые Cycle/AS/Report. Процент промежуточного адаптивного плана
не вычисляется. Существующие исторические данные не удаляются.

Транзакции: базовый SQL атомарен; marker фиксируется вместе с ним. Добавочные
миграции выполняются своей существующей транзакцией; schema_hash выставляется
только после успеха всех шагов. Частично подготовленный известный v1 допускает
повтор. Незнакомая непустая схема, иной source_hash, изменение структуры/constraints,
indexes/triggers отклоняются, без автоматического «ремонта».

`schema_hash` включает каталог таблиц/типов/nullability/defaults, constraints,
indexes и triggers. Данные не включены: повторный запуск сохраняет snapshots.
Существующие рабочие БД не принимаются и не мигрируются этим инструментом.
